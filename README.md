## Ажиллуулах

Windows дээр [Node.js](https://nodejs.org) 20+ суулгасан байх шаардлагатай.

```bash
cd game
npm install      # анх нэг удаа
npm run dev      # хөтчид http://localhost:5173 нээгдэнэ
npm test         # тест
npm run build    # dist/ — вэб хуудас болгон тавих
```

Тоглоомын хурд: `1`, `2`, `3` товч (1×, 2×, 4×). Хулганаар камер эргүүлнэ.

## Хавтасны бүтэц

```
data/              тоон утгууд (JSON) — тэнцвэр тааруулахдаа зөвхөн эдгээрийг засна
game/src/sim/      Three.js-гүй симуляц (тест, тэнцвэрийн симулятор ч ашиглана)
game/src/render/   Three.js дүрслэл
game/tests/        Vitest тестүүд
tools/balance_sim/ тэнцвэрийн симулятор (M1)
docs/              баримтууд
```

## Нэг өгүүлбэрээр

Өвөөгөөсөө энчий хөрөнгө авч бие даасан залуу малчин Хангай эсвэл Говийн аль нэг багаас майхан, цөөн малтай амьдралаа эхэлнэ. Mount & Blade маягаар их газрын зураг дээр чөлөөтэй нүүдэллэж, худалдаа хийн, 3D бууцандаа мал маллаж, сүүгээ боловсруулна. Гэр бүл зохиож, эцэст нь **Мянгат малчин** болно.

## Тоглоомын тулгуур зарчмууд

1. **Улирал бол хаан:** Байгаль хуваарийг тогтооно, тоглогч түүнд дасан зохицно.
2. **Ажил бүр утгатай:** Сүү саахаас эхлээд ааруул хатаах хүртэл бодит ахуйгаас гаралтай.
3. **Ёс заншлыг үйлдлээр сурна:** Хичээл заахгүй, хүндлэлээр мэдрүүлнэ.
4. **Жижгээс том руу:** Майхнаас мянган малтай айл хүртэл ахиц тод мэдрэгдэнэ.
