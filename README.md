# НҮҮДЭЛ: Дөрвөн улирал

> Монгол нүүдэлчин ахуй, ёс заншил, хөдөөгийн байгалийг харуулсан 3D малчны амьдралын симулятор.

**Төлөв:** MVP «Зуслан» — код M0–M5.5, B бэлэн; одоо дүрслэл V0–V5 (`docs/plan/V.md`), дараа нь M6 хадгалалт (`docs/plan/M6.md`). Дэлгэрэнгүй: `docs/CONTEXT.md`, дууссан ажил: `CHANGELOG.md`.
**Хувилбар:** GDD v0.2 (2026-11-12) + MVP «Зуслан» тодорхойлолт (2026-11-13)

## MVP «Зуслан» ба баримтын давуу эрх

MVP-ийн хүрээ: 1 аймаг 1 сум, 4 улирал, шөнөтэй, Farm Frenzy маягийн бүтээгдэхүүн цуглуулалт, туслах малчид, бууц сэлгэх. Хөдөлгүүр: **TypeScript + Three.js.**

Баримтын эх сурвалж = repo-ийн `docs/` (claude.ai Project-д давхар хадгалахгүй). Ажлын дүрэм: [AGENTS.md](AGENTS.md); төслийн зураглал: [docs/CONTEXT.md](docs/CONTEXT.md); баримтын жагсаалт ба давуу эрхийн дараалал: [docs/INDEX.md](docs/INDEX.md).

Кодын бүх тоон утга `data/*.json`-д бий.

## Ажиллуулах

Windows дээр [Node.js](https://nodejs.org) 20+ суулгасан байх шаардлагатай.

```bash
cd game
npm install      # анх нэг удаа
npm run dev      # хөтчид http://localhost:5173 нээгдэнэ
npm test         # тест
npm run build    # dist/ — вэб хуудас болгон тавих
npm run balance -- --seeds 12 --days 220   # тэнцвэрийн симулятор
npm run balance -- --seeds 8 --days 220 --time.animalYearDays 40   # утга өөрчилж туршина
npm run balance -- --seeds 12 --days 220 --only Дунд,Үлддэг --wolves.attack.enabled 0   # стратеги сонгох, чоно унтраах
```

**Удирдлага (M4):** WASD/сум — алхах (Shift — гүйх), газар дээр дарах — тийш явах, хулгана чирэх — камер, дугуй — ойртуулах · E — түүх/агуулахад хийх (ойртоход автоматаар) · B — агуулах, боловсруулалт · T — сумын төв (нохой ч авна) · M — бууц сэлгэх · K — нохойн команд · N — бүх нохой намайг дага · Z — хамгаалалтын бүс · Space — «Хөөе!» · U — уурга · F — морь унах/буух · H — морь дуудах · Q — чоно үргээх · 1/2/3 — хурд · G — бэлчээрийн дулааны зураг · F1 — тусламж · ` — туршилтын цэс.

Гүйцэтгэлийн туршилт: `http://localhost:5173/?herd=300` (баруун дээд буланд FPS).

## Хавтасны бүтэц

```
data/              тоон утгууд (JSON) — тэнцвэр тааруулахдаа зөвхөн эдгээрийг засна
game/src/sim/      Three.js-гүй симуляц (тест, тэнцвэрийн симулятор ч ашиглана)
game/src/render/   Three.js дүрслэл (terrain, animals, characters, camera, scene)
game/src/input/    гар, хулгана → Command
game/tests/        Vitest тестүүд
tools/balance_sim/ тэнцвэрийн симулятор (M1, M4: чоно, нохой, «Үлддэг» стратеги)
docs/              баримтууд
```

## Нэг өгүүлбэрээр

Өвөөгөөсөө энчий хөрөнгө авч бие даасан залуу малчин Хангай эсвэл Говийн аль нэг багаас майхан, цөөн малтай амьдралаа эхэлнэ. Mount & Blade маягаар их газрын зураг дээр чөлөөтэй нүүдэллэж, худалдаа хийн, 3D бууцандаа мал маллаж, сүүгээ боловсруулна. Гэр бүл зохиож, эцэст нь **Мянгат малчин** болно.

## Тоглоомын тулгуур зарчмууд

1. **Улирал бол хаан:** Байгаль хуваарийг тогтооно, тоглогч түүнд дасан зохицно.
2. **Ажил бүр утгатай:** Сүү саахаас эхлээд ааруул хатаах хүртэл бодит ахуйгаас гаралтай.
3. **Ёс заншлыг үйлдлээр сурна:** Хичээл заахгүй, хүндлэлээр мэдрүүлнэ.
4. **Жижгээс том руу:** Майхнаас мянган малтай айл хүртэл ахиц тод мэдрэгдэнэ.
