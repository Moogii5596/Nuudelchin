# Өрсөлдөгчийн шинжилгээ — Herding Adventures (+ сүрэг туух механикийн тойм)

> **Төлөв:** 📚 Судалгаа (2026-11-15). Санаа зээлэх, алдаанаас сэрэмжлэх лавлагаа — дүрэм биш.
> **Анхаар:** Тоглоом **гараагүй** (alpha, «удахгүй»; demo бий). Сэтгэгдэл, шүүмж **байхгүй** — бүх мэдээлэл хөгжүүлэгчийн Steam хуудаснаас. Тиймээс энэ файлд **бусад жижиг сүрэг туух тоглоомуудын механикийг** (§4) нэмж, манай туух системд хэрэгтэй шийдлүүдийг нэгтгэв.
> **Яагаад чухал вэ:** Манай гол механик — сүрэг туух (`prototype-rules.md` §4–5, `herder.ts`) — Herdling-д эвгүй байсан (`herdling.md` Z1–Z3). Herding Adventures яг энэ механикийг **«бодит, ур чадвар шаардсан»** гол тоглоом болгож байна.
> **Дугаарлалт:** HA1–HA10.
> 🙋 **Дараа шалгах:** гарсны дараа (эсвэл demo-г тоглож) удирдлага, сүргийн зан төрхийн чанарыг үнэлэх.

## 2. Гол санаа — «Удирдлага биш, дарамт»

- Хонийг **командаар биш**, байрлал, хөдөлгөөнөөр **нөлөөлнө**. Хэт хурдан хөдөлбөл тарна.
- Хонь **бөөгнөрнө, дарамтад сандарна, хуваагдана, дахин нийлнэ** — тоглогч, нохойны хөдөлгөөнөөс хамаарна.
- **Нохойны байрлал гол**: буруу байрлал сүргийг тараана, зөв байрлал нарийн удирдана. Өөрийн хөдөлгөөн ↔ нохойны байрлалын тэнцвэр — эзэмших ур чадвар.
- Чоно сүрэгт дайрна; хонь төөрнө; **жижиг алдаа хуримтлагдана**.
- Хотуудын хооронд ой, задгай газар, мушгиа замаар **сүрэг туух ажил** авна; аюулгүй хүргэсэн хонины тоогоор шагнал.
- Ур чадвар ахих тусам илүү том, урьдчилан таамаглахад хэцүү сүрэг удирдана.
- Эхэндээ тайван, алдаа гарах тусам хурцадмал байдал өснө.

## 3. Үнэлгээ (хөгжүүлэгчийн амлалт дээр үндэслэсэн)

**Боломжит давуу тал:**
1. Сүргийн **бодит зан төрх** (бөөгнөрөх, сандрах, хуваагдах, нийлэх) — Herdling-ийн «робот тоос сорогч» асуудлын эсрэг.
2. **Нохой + хүн хос** удирдлага — бодит малчдын арга.
3. **Ур чадварын ахиц** — нэг механикийг гүнзгийрүүлж, урт хугацааны сонирхол.
4. «Хонь бүр чухал» — сэтгэлийн оролцоо.

**Эрсдэл (бидний дүгнэлт):**
1. **MMO + жижиг баг** — хамрах хүрээ хэт өргөн (Nomad Y2-той ижил).
2. **Ур чадварын хатуу механик + «Relaxing» тэмдэглэгээ** зөрчилтэй — тайван тоглогчдод хэцүү байж магадгүй.
3. **AI-аар хийсэн маркетинг** — Steam-ийн зарим тоглогч сөрөг хүлээж авдаг.
4. Интернетгүй тоглох боломжгүй.

## 4. Сүрэг туух механикийн тойм (бусад тоглоомууд)

| Тоглоом | Удирдлагын арга | Бидэнд хэрэгтэй санаа |
|---|---|---|
| **Herdling** | Хүн ардаас түлхэнэ, курсор чиглэл заана | Курсор бодит хөдөлгөөнтэй таарахгүй байсан — сургамж (`herdling.md` Z1) |
| **Herding Adventures** | Хүн + нохой, дарамт, байрлал | Нохой бол туслах биш, удирдлагын **хоёр дахь гар** |
| **Shepherd and Dog** | Хонь **малчныг дагана**, **нохойноос зугтана** | **Татах + түлхэх** хос хүч — хоёр өөр хэрэгсэл |
| **Sheepkeeper** | Хуцах нь хонийг нохойноос **түлхэнэ** — чиглүүлэх, хуваах, цуглуулах | «Хуцах» = нэг товчлуурын түлхэлт |
| **Top Dog: Farmyard Adventures** | Нохой гүйх **замыг зурна** | Зам зурах — утас, мэдрэгч дэлгэцэд тохиромжтой |
| **Sheep's Best Friend** | Зөвхөн хулганаар нохойд команд | Нэг товчлуурын хялбар удирдлага |
| **Sheepherds!** | Co-op нохойнууд; хүндрэлийг үе бүрт чөлөөтэй тохируулна | Ганцаараа туух **маш хэцүү**, хамтдаа амар — тохируулга чухал |

## 5. Манай тоглоомд хамаарах сургамж

Манайд одоо: уурга барихад мал 6 м (мориор 8.5 м) зайнаас зугтана, «Хөөе!» — ойрын 18 м мал малчнаас эсрэг зүг рүү, нохойд «сүргийг хамгаал» команд (`prototype-rules.md` §4–5, `milestones.md` M4). Өөрөөр хэлбэл **түлхэх** механик бий, **татах** болон **нохойгоор туух** байхгүй.

### 5.1 Авах санаа 🟢

| # | Санаа | Манайд хаана | Тайлбар |
|---|---|---|---|
| HA1 | **Татах ↔ түлхэх хос хүч** | `herder.ts` | Уураггүй үед мал малчнаас айхгүй — үүнийг өргөтгөж: **уураггүй, удаан алхахад** ойрын мал малчныг **дагана** (бодит амьдралд хонь танил малчныг дагадаг, «хурай, хурай» дуудлага). Уурга барихад түлхэнэ. Хоёр хэрэгсэл → «арын дугуйгаар жолоодох» (Z2) асуудал багасна |
| HA2 | **Нохой — хоёр дахь гар** | `dogs.ts` | Одоо нохой зөвхөн чоноос хамгаална. Нэмэх: **«Энд тууж ир»** (Z2б) — газрын цэг заахад нохой сүргийн нөгөө талаас тойрч очиж малчин руу/хот руу тууна. Монгол банхар бодитоор мал хашдаг |
| HA3 | **Хуцах = нэг товчлуурын түлхэлт** | `dogs.ts` | Нохой хуцахад ойрын мал нохойноос холдоно (Sheepkeeper). «Хөөе!»-тэй адил, гэхдээ нохойн байрлалаас |
| HA4 | **Зам зурах (утсанд)** | `architecture.md` §11 утас | Мэдрэгч дэлгэцэд нохой/сүрэг явах замыг хуруугаар зурах (Top Dog) — утасны удирдлагад туух хамгийн хялбар арга байж магадгүй |
| HA5 | **Сүргийн бодит зан** | `herds.ts` | Бөөгнөрөх, **дарамтад сандрах** (хэт ойр/хурдан ирвэл тарах), хуваагдах, дахин нийлэх. Манайд «тасарсан цөөн мал том сүрэг рүүгээ нийлнэ» бий ✅; нэмэх: малчин **давхиж** ирэхэд сүрэг тарах, **алхаж** ирэхэд тайван хөдлөх |
| HA6 | **Туух ур чадвар ахих** | V1 (MD4-тэй нийлнэ) | Туух тусам түлхэлтийн радиус нарийсч, мал тарах нь багасна — «туршлагатай малчин» мэдрэмж |
| HA7 | **Хүргэсэн малаар шагнал** | V1, хөрш | Хөршийн малыг өөр бууцанд хүргэх, сумын төв рүү мал туух (зарах) ажил — алдсан мал = бага цалин |

### 5.2 Зайлсхийх зүйл 🔴

| # | Эрсдэл | Манайд юу хийх |
|---|---|---|
| HA8 | **Хэт хатуу ур чадвар тайван тоглоомд** | Туух механик тайван тоглогчдод **уучлалтай** байх: тайван горимд сүрэг илүү номхон, түлхэлт өргөн (MD6, Sheepherds-ийн тохируулга). Ур чадвар хүссэн хүнд «бодит» горим |
| HA9 | **MMO / онлайн шаардлага** | MVP-д огт үгүй. PWA-ийн интернетгүй тоглолтыг хадгалах (`architecture.md`) |
| HA10 | **AI-аар хийсэн маркетинг** | Steam хуудас, трейлер, логог хүн хийх эсвэл AI ашигласан бол ил тод мэдэгдэх (Steam заавал шаарддаг). Соёлын тоглоомд жинхэнэ уран бүтээл итгэл төрүүлнэ |

## 6. Туух механикийн нэгдсэн санал (Herdling + Herding Adventures + бусад)

Бүх судалгаанаас гаргасан **туух системийн M6-ийн санал** (батлах 🙋):

1. **Уураггүй алхахад → мал дагана** (HA1, татах).
2. **Уурга барихад → мал зугтана** (одоо бий, түлхэх).
3. **«Хөөе!» → ойрын сүрэг малчнаас эсрэг** (одоо бий).
4. **Давхихад → мал тарна, алхахад → тайван** (HA5).
5. **Нохойд «энд тууж ир»** (HA2 = Z2б).
6. **Сүргийн удирдагч** — бусад нь дагана (`herdling.md` H1).
7. **Газар дээр чиглэлийн заагч** — бодит хөдөлгөөнтэй таарч байгаа эсэхийг тестээр шалгах (`herdling.md` H3, Z1).
8. **Гацалт илрүүлэгч + мал аюул руу гүйхгүй** тест (`khiimori.md` X1, `herder.md` R8).
9. **Тайван горимд** номхон сүрэг (HA8).
