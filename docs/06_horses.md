# 06. Морь

Морь бол малчны хамгийн ойр нөхөр. Тоглоомд морь бүр **нэртэй, зан чанартай, хувийн үзүүлэлттэй** байна.

> **Говийн бүсэд адуу тэжээх боломжгүй** ([11_world_weather.md](11_world_weather.md) §4). Говийн тоглогч тэмээ унаж, **тэмээн уралдаанд** оролцоно (§9). Говийн тоглогч морин уралдаанд оролцохыг хүсвэл морио завсрын сумын айлд тавьж маллуулна.

## 1. Үзүүлэлтүүд

| Үзүүлэлт | Хүрээ | Нөлөө |
|---|---|---|
| Хурд | 1–100 | Аялал, уралдаан |
| Тэсвэр | 1–100 | Холын зам, урт уралдаан, шуурга |
| Номхон | 1–100 | Унахад хялбар, уурга, айх магадлал |
| Ухаан | 1–100 | Мэргэшил сурах хурд, бие даасан үйлдэл |
| Ядаргаа | 0–100 | Өндөр бол хурд, тэсвэр буурна; амрааж бууруулна |
| Эрүүл мэнд | 0–100 | Бэртэх, өвчлөх |
| Эзэнтэйгээ ойр дотно байдал | 0–100 | Сайн харилцвал бүх үзүүлэлт +10% |

**Үзүүлэлт өсгөх арга:** Өдөр бүр унах, сургах, сойх, тэжээх. Морь хооронд хээлтүүлэхэд унага эцэг эхийнхээ дундаж үзүүлэлтийг ±10 хазайлттай өвлөнө.

| 3 | Шүдлэн | Сургаж эхэлнэ |
| 4 | Хязаалан | |
| 5 | Соёолон | |
| 6+ | Их нас | Бүрэн хүчин чадал |
| — | Азарга | Эр, хээлтүүлэгч |
| 15+ | Хөгшин | Үзүүлэлт аажмаар буурна |

## 3. Мэргэшил (Perks)

Морь бүр 1–2 мэргэшилтэй төрнө. Ухаан өндөр бол сургуулилтаар 4 хүртэл болгож болно.

| Мэргэшил | Нөлөө | Сургах арга |
|---|---|---|
| 🐑 Хариулгын морь | Мал хураах хурд ×2, хариулах хүч −50% | Өдөр бүр мал хураахад унах |
| 🪢 Уургын морь | Уурга шидэх амжилт +50% | Уургаар адуу барих |
| 📦 Ачааны морь | Ачаа 1 → 2 АН, тэрэг чирэх | Ачаа зөөх |
| 🧠 Ухаантай морь | Төөрсөн малыг олно, шуурганд эзнээ гэрт нь буцаана | Ухаан 70+ бол аяндаа |
| 👂 Сэрэмжтэй морь | Чоно ойртохоос 1 цагийн өмнө анхааруулна | Шөнийн манаа |
| ❄️ Тэсвэртэй морь | Шуурга, цасанд хурд буурахгүй | Өвөл хол аялах |
| 🏆 Хурдан морь | Уралдааны үндсэн мэргэшил | Уях, сунгаа |

## 4. Морь худалдаж авах

| Морь | Үнэ | Тайлбар |
|---|---|---|
| Нутгийн морь | 1,200,000 | Үзүүлэлт 30–50, 1 мэргэшил |
| Номхон унаа | 1,000,000 | Номхон 80+, бусад нь бага |
| Уралдааны угшилтай даага | 2,500,000 | Хурдны боломж 60–80, сургах шаардлагатай |
| Галшар | 3,500,000 | Хурд 70+ |
| Цолтой хурдан морь | 10,000,000+ | Цолтой, хээлтүүлгийн үнэ цэнэтэй |

**Морин зах:** Сумын төвд улирал бүр, аймгийн төвд Наадмын өмнө.

## 5. Уралдааны морь ба тогтмол орлого

### 5.1. Бэлтгэл
| Бэлтгэл | Тайлбар | Эрсдэл |
|---|---|---|
| **Сунгаа** | Илүү таргыг буулгаж, уралдааны биеийн байдалд оруулна | Хэт хийвэл тэсвэр буурна |
| **Уях** | Сэрүүнд уяж, ус, тэжээлийг хянана | |
| **Хурдлуулах** | Богино хурдны давтлага | Ядаргаа их |

- **Бэлтгэлийн хувь (0–100%):** 80–95% байх нь хамгийн тохиромжтой.
- 100%-иас хэтэрвэл «хэт ачаалал» болж, бэртэх магадлал огцом өснө.

### 5.2. Унаач
- Уламжлал ёсоор хүүхэд унаач унана.
- Өөрийн хүүхэд 7 настайгаасаа унаач болно ([07_family_npc.md](07_family_npc.md)). Эсвэл унаач хөлслөнө: 50,000₮ / уралдаан.
- Унаачийн ур чадвар үр дүнд ±10% нөлөөлнө.

### 5.3. Уралдааны хуваарь

| Уралдаан | Хэзээ | Шагнал (1 / 2 / 3 / 4–5 дахь) | Нөхцөл |
|---|---|---|---|
| Сумын хаврын уралдаан | Хавар, 10 дахь өдөр | 800k / 500k / 300k / 150k | |
| Сумын наадам | Зун, 2–6 дахь өдөр (сум бүр өөр өдөр) | 800k / 500k / 300k / 150k | Аль ч сумын наадамд очиж болно |
| Аймгийн наадам | Зун, 8 (Хангай), 9 (Говь) дахь өдөр | ×3 | Аль нэг сумын наадамд эхний 5-д орсон |
| **Улсын баяр наадам** | Зун, 11–13 дахь өдөр | ×10 + цол | Аймгийн эхний 5-д орсон |
| Сумын намрын уралдаан | Намар, 10 дахь өдөр | 800k / 500k / 300k / 150k | |
| Цагаан сарын уралдаан | Хавар, 3 дахь өдөр | 600k / 400k / 200k / 100k | |

Насны ангилал бүрээр тусдаа уралддаг тул олон морьтой тоглогч нэг наадамд хэд хэдэн шагнал авч болно.

**Наадмын аялал:** Сумын наадмууд өөр өөр өдөр болдог тул тоглогч их газрын зураг дээр сумаас сум руу аялж, хэд хэдэн наадамд оролцож болно (Mount & Blade-ийн тэмцээний аялал шиг). Гэхдээ энэ хугацаанд сүрэг нь хараа хяналтгүй үлдэнэ ([11](11_world_weather.md) §6.3).

| Сумын төрөл | Уралдаан |
|---|---|
| Хангайн цэвэр сум | Морин уралдаан |
| Завсрын сум | Морин уралдаан + тэмээн уралдаан |
| Говийн цэвэр сум | Тэмээн уралдаан |

### 5.4. Цол

| Цол | Нөхцөл | Нөлөө |
|---|---|---|
| **Айргийн тав** | Эхний 5-д орох | Морины үнэ ×1.5, хүндлэл +5 |
| **Түрүү** (Түмний эх) | Улсын наадамд 1-р байр | Морины үнэ ×3, хүндлэл +20, онцгой хүлээн авалт |
| **Аман хүзүү** | 2-р байр | Морины үнэ ×2 |

> Уралдааны цол, шагналын нэршлийг Монгол наадмын уламжлалт нэршилтэй тулгаж баталгаажуулна.

Хурдан угшилтай унагыг үнэтэй зарж болно: эцэг эхийнх нь цолноос хамаарч 2,000,000–8,000,000₮.

## 8. Морь ба Хүндлэл

- Морио зодохгүй, сайн арчилбал хүндлэл нэмэгдэнэ.
- Хурдан морио Наадамд уралдуулахад айл саахалт ирж дэмжинэ.
- Уралдааны морины **цолыг дуудах** болон **ерөөл** нь мини дүрслэл (cutscene) хэлбэрээр гарна.

## 9. Тэмээн уралдаан (Говь, завсрын бүс)

Говийн тоглогчийн морин уралдааныг орлох систем. Морины системтэй ижил бүтэцтэй тул кодонд нэг ерөнхий **RacingAnimal** системээр хийнэ.

| Морь | Тэмээ |
|---|---|
| Хурд, тэсвэр, номхон, ухаан | Ижил үзүүлэлт; тэсвэрт илүү жин өгнө |
| Насны ангилал (даага … их нас) | Тэмээний насны ангилал (баталгаажуулах) |
| Сунгаа, уях | Тэмээний уралдааны бэлтгэл (баталгаажуулах) |
| Хүүхэд унаач | Унаач |

| Уралдаан | Хэзээ | Шагнал |
|---|---|---|
| Говийн сумдын наадам | Зун, 2–6 дахь өдөр | Морин уралдаантай ижил |
| Говь аймгийн наадам | Зун, 9 дахь өдөр | ×3 |
| **Тэмээний баяр** | Өвөл, 12 дахь өдөр, Говь аймгийн төв | ×5, тэмээн поло, тэмээний гоёлын уралдаан |

**Тэмээний мэргэшил:** Ачааны тэмээ (4 АН), уралдааны тэмээ, номхон унаа, усны мэдрэмжтэй (ган болоход ус олно).

> Тэмээн уралдааны насны ангилал, зай, уламжлалыг говийн малчид, уралдаан зохион байгуулагчдаас лавлаж баталгаажуулна ([15](15_decisions_open_questions.md) V8).
