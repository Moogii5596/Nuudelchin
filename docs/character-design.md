# Хүний дүрийн загвар (үндсэн дүр, NPC)

> Үе шат: [[V]] V4.4 (үндсэн дүр — кодонд), V4.5 (нэг кодын сан ба NPC — төлөвлөсөн, §4). Хэв маяг, соёлын нарийвчлал: [[visuals-plan]] §3.
> Загварын лаборатори: `tools/character-lab/herder.html` (хөтчөөр шууд нээнэ; интернэт хэрэгтэй — Three.js-ийг CDN-ээс авна). Загварыг эхлээд тэнд засаж хэрэглэгчээр батлуулаад, дараа нь код руу хуулна.

## 2. Үндсэн дүр — хэрэгжилт (V4.4, кодонд)

- **Загвар:** `game/src/render/herderModel.ts` — `makeHerderModel`, `dressHerderModel`, `animateHerder`. Геометрийн код лабораторийн файлаас **хуулсан** тул тэр хэсэг `@ts-nocheck`; гадагш гарах API төрөлтэй. Canvas текстур эхний дуудалтад үүснэ (тест DOM шаардахгүй).
- **Холболт:** `render/characters.ts` → `CharactersView` зөвхөн **тоглогчид** шинэ загварыг хэрэглэнэ. Туслах, газрын зургийн малчин хуучин `makeHerder`-ээр үлдсэн (§4 R5).
- **Хөдөлгөөн:** хурднаас алхаа → гүйлт (өвдөг, тохой, бэлхүүс, хүзүү, амьсгал), морь унасан, тэрэг/машинд суусан, дуудахад гар өргөх, уурга атгах. Тоо → `data/visuals.json` `herderAnim`.
- **Нүүр:** анивчих, харц; дуудлагын бичиг гарч байх үед ам хөдөлнө. Сэтгэл хөдлөл (`herderAnim.events`):

| Үйл явдал | Эх сурвалж (render талд, sim өөрчлөөгүй) | Дараалал |
|---|---|---|
| `birth` төл гарах | `state.today.births` өсөх | гайхах → баярлах |
| `loss` мал хорогдох | `state.today.deaths` + `wolfKills` өсөх | гайхах → гуниглах |
| `wolf` чоно дайрах | бууцанд `hunt`/`drag` горимтой чоно гарч ирэх; үргэлжлэх хугацаанд `threat` | гайхах → уурлах |
| `shout` / `scare` / `call` | тоглогчийн дуудлага (`CharactersView.say`) | уурлах / уурлах / баярлах |

- **Гүйцэтгэл (2026-11-15):** дүрийг араг ястай нэг mesh болгосон (`bakeSkinned`, зөвхөн тоглоомд): үе мөчний бүлгүүд яс болж хэвээр хөдөлнө, давхарга (body:*, hat:*) бүрийн хэсгүүд материалаар нэгтгэгдэнэ, нэг өнгийн материалууд оройн өнгө болж нийлнэ, бэхэн хүрээ давхарга бүрт нэг mesh. Нүүрний canvas 512 × 256. Дүрийн draw call **428 → 39** (тоглоомын бусад хэсэг ~130), харагдах байдал ба хөдөлгөөн өөрчлөгдөөгүй (өмнө/дараа зургаар шалгасан).
- **Шалгасан:** typecheck, бүх тест, build; тоглоомыг ажиллуулж зун/өвлийн хувцас, зогсох, морь унасан байдлын дэлгэцийн зураг. **Шалгаагүй** (→ [[playtest]] V4.4): алхаа/гүйлтийн хөдөлгөөний мэдрэмж, утасны FPS.

### Мэдэгдэж буй дутагдал

- Алхах/гүйхэд хөл урт хормойг нэвтэлнэ (хормой хөлийг дагадаггүй).
- Нүүрний текстур нэг (бүх дүрд хуваалцана) — одоо зөвхөн тоглогч хэрэглэдэг тул асуудалгүй; NPC-д атлас (§4.4).
- Гурвалжин ~110 мянга (нэг дүрд). Олон NPC-д `npc`/`crowd` нарийвчлал хэрэгтэй (§4 R4).
- C-5 (хувцас солих): лабораторид дээлний 5 өнгө, малгайн сонголт бий; тоглоомд хараахан холбоогүй (🙋 §5).
- Малгайгүй үеийн үс, өвлийн үсэн захны дүрслэл бүдүүлэг.

## 4. Нэг кодын сан: дүр бүрийг тохиргооноос угсрах (V4.5)

**Зорилго:** тоглогч, туслах, сумын оршин суугч, хамаатан бүгд **нэг кодоор** угсарна. Дүр хооронд зөвхөн **царай, гадаад төрх (үс, хувцас, өнгө), өндөр/нуруу** ялгаатай — эдгээр нь кодонд биш, `data/characters.json`-д. Шинэ NPC нэмэхэд код бичихгүй, тохиргоонд нэг мөр нэмнэ.

### 4.1 Одоогийн давхардал

| Давхардал | Хаана | Шийдэл |
|---|---|---|
| Загварын бүх код хоёр газар: лаборатори (`tools/character-lab/herder.html`) ба `herderModel.ts` («хуулж» шинэчилдэг) | лаб ↔ тоглоом | Лабораторийг тоглоомын модулиудаас импортлодог Vite хуудас болгоно (R6) — нэг эх сурвалж |
| Хуучин `makeHerder` (characters.ts) ба `resident()` (sumcenter.ts) — хүний 3 өөр загвар | `characters.ts`, `sumcenter.ts`, `staff.ts`, `worldmap.ts` | Бүгд `buildCharacter(spec)`-ийг дуудна; хуучныг устгана (R5) |
| `makeHerder(colors)` нэг том функц: хувцас, гар, хөл, толгой, малгай бүгд дотроо, тоо хатуу бичигдсэн | `herderModel.ts` | Хэсэг бүр параметртэй тусдаа функц (R1) |
| Текстур, материал дүр бүрд дахин үүснэ (нүүрний canvas нэг, бусад нь модулийн түвшинд) | `herderModel.ts` | Өнгө/зургаар кэштэй нэг сан (R2) |
| Анимац (`animateHerder`) зөвхөн тоглогчид | `herderModel.ts`, `characters.ts` | Аль ч дүрд ажиллах `animateCharacter(rig, pose)` — аль хэдийн ерөнхий, нэрийг нь л солино (R1) |

### 4.2 Зорилтот бүтэц

```
game/src/render/character/
  spec.ts        CharacterSpec төрөл + data/characters.json-ийг шалгах (style.ts-ийн загвараар)
  materials.ts   кэштэй материал/текстур: эсгий, торго (хээ × өнгө), үс, гутал, бэхэн хүрээ
  geom.ts        ерөнхий хэрэгсэл: profile, lathe, loft, tube, cyl, sball, fluff, ring
  parts/
    head.ts      цилиндр толгой, үс (үсний загвар), малгайн суурь өндөр
    face.ts      нүүр зурах: царайны параметр + сэтгэл хөдлөл → canvas; тоглогч — амьд canvas, NPC — атлас
    torso.ts     дээл/тэрлэг/өвлийн дээл, энгэр, товч, бүс, хормой, хантааз
    arm.ts       ханцуй, бугуй, гар, хуруу, атгах (curl)
    leg.ts       гуя, өвдөг, гутал
    hats.ts      тоорцог, үстэй монгол малгай, … (шинэ малгай = шинэ функц + нэр)
  rig.ts         buildCharacter(spec, detail): хэсгүүдийг угсарч, хэмжээг ясаар тохируулж, bakeSkinned
  animate.ts     animateCharacter(rig, pose) — алхаа, гүйлт, морь, суух, гар өргөх, нүүр
  cache.ts       ижил spec+detail-тэй дүрүүд нэгтгэсэн геометрээ хуваалцана (яс тус бүр)
```

**Гол дүрэм:** `parts/*` функц бүр `(spec, ctx) → Group` бөгөөд тоо хэмжээг зөвхөн `spec`-ээс авна; хатуу бичсэн тоо зөвхөн «загварын хэлбэр» (профайлын муруй) байж болно. Шинэ гадаад төрх = `characters.json`-д тохиргоо, шинэ ХЭЛБЭР (жишээ нь эмэгтэй малгай) = `parts/hats.ts`-д нэг функц.

### 4.3 Дүр хооронд ялгаатай зүйл (`CharacterSpec`)

| Бүлэг | Параметр | Жишээ утга | Хэрэгжих арга |
|---|---|---|---|
| **Өндөр, нуруу** | `stature` (нийт өндөр), `build` (өргөн), `headRatio` (толгойн харьцаа) | хүүхэд 0.7 / 1.25, эмэгтэй 0.94, өвгөн 0.96 + бөгтөр | Угсарсны дараа, bake-ээс **өмнө** ясны бүлгүүдийг масштаблана (хөл — урт, цээж — өргөн, толгой — харьцаа). Ингэвэл анимац, геометр өөрчлөгдөхгүй |
| **Царай** | `skin`, `eyes` (дугуй/зууван/нарийн), `brows` (зузаан, налуу), `mouth` (өргөн), `beard` (үгүй/сахал/сэвсгэр), `wrinkles`, `blush` | эрэгтэй — зузаан хөмсөг, сахалгүй; өвгөн — сахал, үрчлээ | `face.ts` — зөвхөн зурах параметр; сэтгэл хөдлөл, анивчих, ярих бүх дүрд нэг |
| **Үс** | `hair.style` (богино, гэзэг, хоёр гэзэг, халзан), `hair.color` | эмэгтэй — хоёр гэзэг; өвгөн — саарал | `head.ts` үсний загвар бүр нэг функц |
| **Хувцас** | `deel` {өнгө, хээ, хормойн өнгө}, `sash`, `hat` (нэр эсвэл «улирлаар»), `boots`, `vest` | туслах — үүргийн өнгө (одоогийн `helperRoles`) | `torso/hats/leg` — өнгө нь материалын кэшээс |
| **Нарийвчлал** | `detail`: `full` (тоглогч) · `npc` (туслах, ойрын) · `crowd` (сумын олон хүн) | — | `npc`: толгой 32 хуваалт, хуруугүй бээлий гар (атгах хэвээр), нэг outline; `crowd`: ясгүй, хөдөлгөөнгүй, нүүр атласаас |

`data/characters.json` жишээ:

```json
{
  "presets": {
    "man":   { "stature": 1.0,  "face": { "eyes": "oval", "brows": "thick" }, "hair": { "style": "short" } },
    "woman": { "stature": 0.94, "face": { "eyes": "oval", "brows": "thin", "blush": 0.15 }, "hair": { "style": "braids" } },
    "elder": { "base": "man", "stature": 0.96, "hunch": 0.08, "face": { "beard": "goatee", "wrinkles": 1 }, "hair": { "color": "#9a9a9a" } },
    "child": { "stature": 0.7, "headRatio": 1.25, "face": { "eyes": "round" } }
  },
  "player": { "base": "man", "deel": { "color": "#2f5d9b" } },
  "helpers": { "herd": { "base": "man", "deel": { "color": "#8a2a2a" } }, "collect": { "base": "child" } },
  "sumResidents": { "pool": ["man", "woman", "elder", "child"], "deelColors": ["#7a3b2a", "#2f5d9b", "#5b3c7c"] }

```

Туслахын хүйс, насыг sim-ээс (`helper.sex`, нас) авч preset-ийг сонгоно — sim өөрчлөгдөхгүй.

### 4.4 Гүйцэтгэл (олон дүр)

- **Яс тус бүр, геометр хуваалцана:** ижил `spec + detail`-тэй дүрүүд нэгтгэсэн геометрээ `cache.ts`-ээс авна (`SkinnedMesh` геометр хуваалцаж, яс нь өөр байж болно). Санах ой, угсрах хугацаа хэмнэнэ.
- **Нүүр:** тоглогч — амьд canvas (одоогийнх). NPC — **атлас**: царайны загвар × сэтгэл хөдлөл × амны 3 байрлал урьдчилан зурсан нэг текстур; NPC бүр текстурын хуулбартай (зураг нэг, зөвхөн UV шилжилт өөр) — кадр бүр GPU руу хуулахгүй.
- **Хязгаар:** `npc` дүр ≈ 25 draw call, `crowd` дүр бүх оршин суугчийг нийлүүлээд 2–3 draw call ([[CONTEXT]] §5-ын хязгаарт).
