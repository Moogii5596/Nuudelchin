# Хүний дүрийн загвар (үндсэн дүр, NPC)

> Үе шат: [[V]] V4.4 (үндсэн дүр — кодонд), V4.5 (NPC — төлөвлөсөн). Хэв маяг, соёлын нарийвчлал: [[visuals-plan]] §3.
> Загварын лаборатори: `tools/character-lab/herder.html` (хөтчөөр шууд нээнэ; интернэт хэрэгтэй — Three.js-ийг CDN-ээс авна). Загварыг эхлээд тэнд засаж хэрэглэгчээр батлуулаад, дараа нь код руу хуулна.

## 2. Үндсэн дүр — хэрэгжилт (V4.4, кодонд)

- **Загвар:** `game/src/render/herderModel.ts` — `makeHerderModel`, `dressHerderModel`, `animateHerder`. Геометрийн код лабораторийн файлаас **хуулсан** тул тэр хэсэг `@ts-nocheck`; гадагш гарах API төрөлтэй. Canvas текстур эхний дуудалтад үүснэ (тест DOM шаардахгүй).
- **Холболт:** `render/characters.ts` → `CharactersView` зөвхөн **тоглогчид** шинэ загварыг хэрэглэнэ. Туслах, газрын зургийн малчин хуучин `makeHerder`-ээр үлдсэн (§4).
- **Хөдөлгөөн:** хурднаас алхаа → гүйлт (өвдөг, тохой, бэлхүүс, хүзүү, амьсгал), морь унасан, тэрэг/машинд суусан, дуудахад гар өргөх, уурга атгах. Тоо → `data/visuals.json` `herderAnim`.
- **Нүүр:** анивчих, харц; дуудлагын бичиг гарч байх үед ам хөдөлнө. Сэтгэл хөдлөл (`herderAnim.events`):

| Үйл явдал | Эх сурвалж (render талд, sim өөрчлөөгүй) | Дараалал |
|---|---|---|
| `birth` төл гарах | `state.today.births` өсөх | гайхах → баярлах |
| `loss` мал хорогдох | `state.today.deaths` + `wolfKills` өсөх | гайхах → гуниглах |
| `wolf` чоно дайрах | бууцанд `hunt`/`drag` горимтой чоно гарч ирэх; үргэлжлэх хугацаанд `threat` | гайхах → уурлах |
| `shout` / `scare` / `call` | тоглогчийн дуудлага (`CharactersView.say`) | уурлах / уурлах / баярлах |

- **Шалгасан:** typecheck, бүх тест, build; тоглоомыг ажиллуулж зун/өвлийн хувцас, зогсох, морь унасан байдлын дэлгэцийн зураг. **Шалгаагүй** (→ [[playtest]] V4.4): алхаа/гүйлтийн хөдөлгөөний мэдрэмж, утасны FPS.

### Мэдэгдэж буй дутагдал

- Алхах/гүйхэд хөл урт хормойг нэвтэлнэ (хормой хөлийг дагадаггүй).
- Нүүрний текстур нэг (бүх дүрд хуваалцана) — одоо зөвхөн тоглогч хэрэглэдэг тул асуудалгүй; NPC-д N1-ээр шийднэ.
- Загвар хүнд: толгой 96 × 56 хуваалттай, mesh бүр бэхэн хүрээний хуулбартай, нүүрний canvas 2048 × 1024. Нэг дүрд зүгээр; олон NPC-д N1-ийн хөнгөн хувилбар хэрэгтэй.
- C-5 (хувцас солих): лабораторид дээлний 5 өнгө, малгайн сонголт бий; тоглоомд хараахан холбоогүй (🙋 §5).
- Малгайгүй үеийн үс, өвлийн үсэн захны дүрслэл бүдүүлэг.

## 4. NPC-үүдийг шинэ загварт шилжүүлэх төлөвлөгөө (V4.5)

Зарчим: **нэг загвар, гурван нарийвчлал.** Ойрын цөөн дүр бүрэн загвар, олон/холын дүр хөнгөн. Үндсэн дүрийг NPC-ээс ялгах тэмдэг (өнгө, малгай) хадгална. Дараалал нь хамаарлаар:

| # | Алхам | Файл | Гарах шалгуур | Хэмжээ |
|---|---|---|---|---|
| N1 | **Загварыг олон дүрд бэлдэх.** (а) Нүүрний canvas/текстурыг дүр бүрт тусад нь (жижиг: 512 × 256) эсвэл сэтгэл хөдлөлийн атлас болгох; (б) `detail: 'full' \| 'npc' \| 'crowd'` сонголт — `npc`: толгойн хуваалт 32, хуруугүй бээлий гар, хүрээгүй эсвэл нэг нэгтгэсэн хүрээ; `crowd`: хөдөлгөөнгүй, материал бүрээр нэгтгэсэн нэг mesh; (в) геометрийн кэш (ижил хэсгийг дүрүүд хуваалцана); (г) `init()`-ийг төрөлжүүлж `@ts-nocheck`-ийг авах | `render/herderModel.ts` | 8 `npc` дүр зэрэг харагдахад draw call ≤ +40, `low` дээр FPS уналтгүй ([[CONTEXT]] §5) | L |
| N2 | **Гадаад төрхийн сонголт** `data/visuals.json` `characters`: хүйс (эрэгтэй/эмэгтэй — үс, малгай, дээлний тайралт), нас (хүүхэд: 0.7 хэмжээ, том толгой; өвгөн: саарал үс, сахал), дээлний өнгө/хээ, малгайн төрөл. Соёлын нарийвчлалыг хэрэглэгч шалгана ([[visuals-plan]] §3.4) | `data/visuals.json`, `render/style.ts`, `render/herderModel.ts` | 6-аас доошгүй ялгаатай төрх; тест тохиргоог шалгана | M |
| N3 | **Туслахууд** шинэ загвараар: дээл үүргээрээ, малгай хүйсээр (одоогийн `helperColors` хэвээр), хүүхэд жижиг. `animateHerder`-оор алхаа, морь унах; ажил хийх поз (саах, хөөх) байвал нэмнэ | `render/staff.ts` | бүх үүргийн туслах шинэ загвартай, улирлаар хувцас солигдоно, `staff.test` хэвээр | M |
| N4 | **Газрын зургийн малчин** — тоглогчийн загварын `npc` нарийвчлал, морь унасан поз | `render/worldmap.ts` | газрын зураг дээр тоглогч танигдана | S |
| N5 | **Сумын төвийн оршин суугчид** — `crowd` нарийвчлал: N2-ийн төрхөөс санамсаргүй (seed-тэй), зогсох/суух 2–3 поз; ойртоход (≤ 12 м) хамгийн ойрын 3–4 нь `npc` болж толгой эргүүлж харна | `render/sumcenter.ts` | оршин суугчид шинэ төрхтэй, сумын төвийн draw call өсөхгүй (нэгтгэсэн хэвээр) | M |
| N6 | **Ярилцлага, сэтгэл хөдлөл** (C-3, C-4): Худалдаачин/банк/хамаатны цонх нээлттэй үед хамгийн ойрын NPC ба тоглогч бие бие рүүгээ харж ам хөдөлнө; наймаа амжилттай → баярлах, татгалзах → гуниглах; туслах чоно харвал гайхах/уурлах. Үйл явдлын жагсаалтыг `herderAnim.events`-д нэмнэ | `render/characters.ts`, `render/staff.ts`, `render/ui/panels.ts` | цонх нээхэд хоёр тал ярилцаж харагдана | M |

Хамаарал: N1 → (N2, N4) → N3 → N5 → N6. N1-гүйгээр N3/N5-ыг хийвэл гүйцэтгэлийн хязгаар эвдэрнэ.
Хүрээнээс гадуур (V1+): хамаатан, Худалдаачны тусгай 3D дүр; гэр доторх хүмүүс; NPC-ийн өдрийн хуваарь.
