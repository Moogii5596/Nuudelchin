# Хөгжүүлэлтийн үе шатууд (MVP «Зуслан»)

> Нүүдэлчин тоглоом. 2026-11-13, сүүлд шинэчилсэн 2026-11-14.
> **Төлөв:** M0–M5.5 ба B код бэлэн. Хэрэглэгчийн шийдвэрээр M6-аас өмнө V0–V5 дүрслэлийн сайжруулалтыг хэрэгжүүлж байна ([[visuals-plan]]); эхний багц кодод орсон, S25 дээрх FPS ба хөрөг зураг баталгаажаагүй.
> Дараалал: шөнө, газрын зураг (M4.5, M4.6) → туслах (M5) → улирал (M5.5) → B → V0–V5 дүрслэл → M6.
> Дүрэм: [[mvp-spec]] (давуу эрхтэй). Архитектур: [[architecture]]. Баримтын хөтөч: [[INDEX]]. Энэ баримт нь хуучин [[14_roadmap_mvp]]-ийн MVP-ийн хэсгийг орлоно.
> Үе шат бүр **гарах шалгууртай.** Шалгуурыг хангасны дараа дараагийн шат руу шилжинэ. Доорх хэсгүүд нь тухайн үеийн байдлыг тэмдэглэсэн; хожмын үе шат өөрчилсөн бол ⚠ тэмдэгтэй.
> Энэ файл claude.ai Project «Монгол» → [[milestones]]-ийн хуулбар.
