# Хөгжүүлэлтийн үе шатууд (MVP «Зуслан»)

> Нүүдэлчин тоглоом. 2026-11-13. Энэ баримт нь хуучин `docs/14_roadmap_mvp.md`-ийн MVP-ийн хэсгийг орлоно (тэр нь 4 улирал, их газрын зурагтай хувилбарт зориулагдсан байсан).
> Дүрэм: `mvp-spec.md`. Архитектур: `architecture.md`.
> Үе шат бүр **гарах шалгууртай.** Шалгуурыг хангасны дараа дараагийн шат руу шилжинэ.

---

| # | Үе шат | Гол агуулга | Гарах шалгуур |
|---|---|---|---|
| **M0** | Бэлтгэл | Архитектур, хавтасны бүтэц, Vite + TS + Three.js төсөл, `data/` JSON-ийн анхны утга, git | `npm run dev` хоосон 3D дүр зураг харуулна, `npm test` ажиллана ✅ |
| **M1** | Симуляцын цөм (3D-гүй) | Цаг, seed RNG, тохиргоо шалгалт, бэлчээрийн тор (ургалт, доройтол), малын бэлчээрлэлт (идэш, тааз, тарга, жин), цангалт, бүтээгдэхүүн унах ба муудах, агуулах, боловсруулалт, зах, өдрийн тайлан | Нэгжийн тестүүд ногоон. `tools/balance_sim` 100 өдрийг < 5 сек-д тоглуулж тайлан гаргана |
| **M1.5** | Эдийн засгийн тэнцвэр | Бодит үнэ, хийсвэр төллөлт, туслахын цалинтай тэнцвэрийг симуляцаар тааруулах | Дунд тоглогчийн стратеги «гэр + 40 хонин толгой»-д 1× хурдаар 4–6 цагт хүрнэ. Зорилтыг хэрэглэгч батална 🙋 |
| **M2** | 3D суурь | Прототипын газар, камер, малчин, морь унах, «Хөөе», чоно үргээх-ийг шинэ бүтэц рүү шилжүүлэх. Малыг InstancedMesh-ээр sim-ээс зурах. Бэлчээрийн өнгө | 300 малтай бууцанд 60 FPS. Мал өвс идэж, газрын өнгө өөрчлөгдөж харагдана |
| **M3** | Бүтээгдэхүүний гогцоо | Сав сүү, ноос газарт унах, түүх, агуулах UI, тогоо/сепаратор/эсгий UI, морин тэргээр сумын төв (зарах, мал/бараа авах), өдрийн тайлангийн дэлгэц | Тоглогч 10 өдөр гараар тоглож, бүтээгдэхүүнээ цуглуулж, боловсруулж, зарж, ашигтай ажиллаж чадна |
| **M4** | Бууц ба чоно | Зуслангийн 3 бууц, нүүх, доройтлын харагдац, голын ус, чонын нутаг, хамгаалалтын бүс, нохой | Нэг бууцанд удаан байхад өвс сулрах нь мэдрэгдэнэ. Нүүх нь бодит шийдвэр болно |
| **M5** | Туслах малчид | Зарын самбар, ганц бие/айл, байр, 5 үүргийн AI (цуглуулагч, жолооч, хоньчин, үхэрчин, адуучин), цалин | 3+ туслахтай тоглогч өөрөө гараар бараг юу ч хийхгүйгээр ферм ажиллана |
| **M6** | Төллөлт, зорилго, хадгалалт | 20 өдрийн мөчлөг, нас, үржлийн эр мал, хөршийн бух, гэр + 40 хонин толгой → төгсгөлийн дэлгэц, хадгалах/ачаалах, англи хэл | Эхнээс нь дуустал бүрэн тоглогдоно. Хадгалж, ачаалахад өгөгдөл алдагдахгүй |
| **M7** | Туршилт ба өнгөлгөө | Гадны 3–5 тоглогчоор туршуулах (хот, гадаад), тэнцвэр, гүйцэтгэл, морин хуурын ая, анхан шатны заавар | Туршсан тоглогчдын ихэнх нь зорилгодоо хүрч, «хөдөөний амьдрал ямар байдгийг мэдэрсэн» гэж хариулна |

## M0 → M1 эхний даалгаврууд

1. `sim/rng.ts`, `sim/clock.ts`, `sim/config.ts` + тест ✅ (M0-д хийгдсэн)
2. `sim/state.ts`: GameState, эхлэлийн төлөвийг `start.json`-оос үүсгэх
3. `systems/pasture.ts`: бэлчээрийн тор, өдрийн ургалт, бууцны доройтол
4. `systems/grazing.ts`: малын цэг сонгох, идэх хурд, өдрийн тааз, цангалт
5. `systems/animals.ts`: өдрийн эцсийн тарга, жин, эрүүл мэнд
6. `systems/production.ts`, `storage.ts`, `processing.ts`: сүү, ноос, муудах, агуулах
7. `systems/market.ts`, `transport.ts`: сумын төв, тэрэгний аялал
8. `tools/balance_sim`: стратегиуд, олон seed, тайлан
