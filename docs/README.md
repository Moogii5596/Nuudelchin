# Баримт бичгийн хөтөч — Нүүдэлчин (Project «Монгол»)

> Монгол нүүдэлчин ахуйг харуулсан 3D тоглоом. **Хөдөөний амьдралд бүрэн автаж, тайвширч суух симулятор** — хожих, юм нээх нь гол биш, тоглоом дуусахгүй (`mvp-spec.md` §10). Зорилго: хөдөөний амьдрал, түүний сорилтыг харуулж, хот болон гадаадын тоглогчдод «өөр ертөнцөд ирсэн» мэдрэмж төрүүлэх.
> Сүүлд шинэчилсэн: 2026-11-14 (M5.5 + B1–B11, MVP-ийн нарийвчилсан төлөвлөгөө, дүрслэлийн төлөвлөгөө, тайван симуляторын зорилго, амьд ертөнцийн алсын хараа). Хөгжүүлэлтийн хавтас: `E:\MoogiiDev\Nuudelchin` (`docs/` дотор эдгээр баримтын хуулбар).

---

## 1. Аль баримт давуу эрхтэй вэ

Зөрчилдвөл дээрх нь хүчинтэй:

1. **`mvp-spec.md`** — MVP-ийн нэгдсэн дүрэм, хэрэглэгчийн шийдвэрийн түүх (§0), бүх нээлттэй шийдвэр (§13).
2. **Хэрэгжүүлэлтийн тэмдэглэл** — үе шат бүрт юу, яаж хийгдсэн: `night-transport.md` (M4.5), `world-map-mvp.md` (M4.6), `helpers-m5.md` (M5), `seasons-camps.md` (M5.5).
3. **`milestones.md`** (үе шат, тэнцвэрийн дүн), **`mvp-plan.md`** (M6–M7-ийн нарийвчилсан төлөвлөгөө, хуваарь), **`visuals-plan.md`** (дүрслэл V0–V5), **`architecture.md`** (код, өгөгдөл).
4. **Дизайны суурь** — MVP-д хэрэгжсэн механикийн үндэслэл: `grazing-livestock.md`, `water-horses-transport.md`.
5. **Түүх** — хуучин утгатай, зөвхөн лавлагаа: `prototype-rules.md`, `economy-mvp.md`, `balance-m1.md`.
6. **V1+ дизайн** — MVP-ийн дараа: `living-world.md` (алсын хараа), `world-map.md`, `family-generations.md`.

Баримт бүрийн эхэнд **Төлөв** мөр бий. Хуучирсан хэсэг ⚠ эсвэл ~~зураастай~~, юугаар солигдсоныг заасан.

- Шинэ шийдвэр гарвал: `mvp-spec.md` §0-д огноотой нэмж, холбогдох хэсгийг засна; хуучин дүрэм бүхий баримтад ⚠ тэмдэг тавьж шинэ газар руу заана.

- Үе шат дуусахад `milestones.md`-д «хийгдсэн зүйл» хэсэг нэмж, энэ хөтчийн «Төлөв»-ийг шинэчилнэ. `mvp-plan.md`-ийн тухайн ажлыг ✅ болгоно.
- Тоон утгыг кодонд биш `data/*.json`-д (`architecture.md` §3.4).
