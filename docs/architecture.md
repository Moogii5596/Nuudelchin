# Техникийн архитектур (MVP «Зуслан»)

> Нүүдэлчин тоглоом. 2026-11-13. Хөдөлгүүр: **TypeScript + Three.js** (хэрэглэгчийн шийдвэр). Энэ баримт нь хуучин `docs/13_technical.md`-ийн хөдөлгүүр сонголтын хэсгийг орлоно. Тэр баримтын зарчмууд (өгөгдөлд тулгуурлах, симуляц ба дүрслэлийг салгах, seed) хэвээр хүчинтэй.
> Тоглоомын дүрэм: `mvp-spec.md` (давуу эрхтэй), `grazing-livestock.md`, `water-horses-transport.md`.

| Хэсэг | Сонголт | Шалтгаан |

## 3. Гол зарчмууд

### 3.1 Симуляц ба дүрслэл тусдаа

```
 Input ──Command──▶  sim (GameState-ийг өөрчлөх ганц газар)  ──Event──▶  UI / дуу
                              │
                              ▼ (уншина)
                           render (Three.js)
```

- `sim/` хавтас Three.js, DOM, `window`-г огт импортлохгүй. Тиймээс тест болон тэнцвэрийн симулятор 3D-гүйгээр ажиллана.
- `render/` зөвхөн GameState-ийг уншиж зурна. Тоглоомын логикийг `render/` дотор бичихгүй.
- Тоглогчийн бүх үйлдэл `Command` болж sim рүү очно. Ингэснээр тоглолтыг дахин тоглуулах (replay), тестлэх боломжтой.

### 3.2 Тогтмол алхамтай цаг

- Симуляцын нэг алхам = **1 тоглоомын минут.**
- 1× хурдаар 1 тоглоомын цаг = 10 сек (прототипын дүрэм), тиймээс 1 алхам ≈ 0.167 сек. 4× хурдаар секундэд 24 алхам.
- Render нь секундэд 60 удаа зурж, хоёр алхмын хооронд байрлалыг зөөлрүүлнэ (interpolation).
- **Давтамж:**

| Хэзээ | Юу |
|---|---|
| Алхам бүр (1 мин) | Хөдөлгөөн, бэлчээрлэх, бүтээгдэхүүн унах, боловсруулалтын явц, чоно |
| 10 алхам тутам | Малын бэлчээрийн цэг сонгох (оноо), туслахын шийдвэр |
| Цаг бүр | Сүүний муудах хугацаа, цангалт |
| Өдрийн эцэс (20:00) | Тарга, жин, эрүүл мэнд, өвсний ургалт, бууцны доройтол, цалин (5 өдөр тутам), өдрийн тайлан, автомат хадгалалт |
| 20 өдөр тутам | Төллөлтийн мөчлөг, нас (хийсвэр, `mvp-spec.md` §9) |

- **3D-гүй горим:** алхмуудыг хамгийн хурдан гүйлгэнэ. Зорилт: 1 тоглоомын өдөр 3D-гүйгээр < 50 мс (1000 малтай).

### 3.3 Давтагддаг санамсаргүй тоо

- `sim/` дотор `Math.random()` хэрэглэхгүй. Бүх санамсаргүй тоо `rng.ts`-ийн seed-тэй генератороос гарна.
- Нэг seed + нэг командын дараалал → яг ижил тоглолт. Алдаа давтан гаргах, тэнцвэр шалгахад чухал.

### 3.4 Өгөгдөлд тулгуурлах

Кодонд тоо шууд бичихгүй. Бүх утга `data/` хавтасны JSON файлд байна:

| Файл | Агуулга |
|---|---|
| `time.json` | Өдрийн эхлэл/төгсгөл, цагийн урт, сарын урт, малын жилийн урт |
| `animals.json` | Мал бүрийн жин, өсөлт, насны шат, төллөлтийн магадлал, цангалт, кг-ын үнэ |
| `pasture.json` | Бэлчээрийн төрөл, өвсний зүйл, улирлын чанар, ургалт, доройтол |
| `camps.json` | Зуслангийн бууцнууд: бэлчээрийн хольц, ус, чонын эрсдэл |
| `products.json` | Сүү, тараг, ноос, ноолуур: унах давтамж, муудах хугацаа, үнэ |
| `processing.json` | Тогоо, сепаратор, эсгий: оролт, гаралт, хугацаа, үнэ |
| `storage.json` | Агуулахын түвшин, багтаамж, үнэ |
| `vehicles.json` | Морин тэрэг, ачааны машин: багтаамж, хурд, бензин |
| `helpers.json` | Туслахын үүрэг, цалин, айлын хөнгөлөлт, байр |
| `economy.json` | Эхлэлийн мөнгө, гэр, өдөр тутмын зардал, худалдан авах үржүүлэгч |
| `wolves.json` | Чонын нутаг, хамгаалалтын бүс, дайралтын магадлал |
| `start.json` | Эхлэлийн сүрэг, тээвэр, агуулах |

- Ачаалахдаа утга бүрийг шалгаж, алдаатай бол тоглоом эхлэхгүйгээр ойлгомжтой алдааны мэдээлэл гаргана.
- Тэнцвэр тааруулахдаа зөвхөн JSON файлыг засна, кодод хүрэхгүй.

## 4. Өгөгдлийн загвар (товч)

```ts
interface GameState {
  version: number;          // хадгалалтын хувилбар
  seed: number; rngState: number;
  time: { day: number; minute: number };   // minute: 06:00 = 360 … 20:00 = 1200
  money: number;
  campId: string;
  camps: Record<string, CampState>;        // бууц бүрийн доройтол, ачаалал
  grass: GrassGrid;                        // одоогийн бууцны тор (Float32Array)
  animals: Animal[];
  items: GroundItem[];                     // газарт унасан бүтээгдэхүүн
  storage: { level: number; stock: Record<ProductId, Batch[]> };
  processors: ProcessorState[];
  vehicles: VehicleState[];
  helpers: Helper[]; housing: Housing[];
  player: PlayerState;
  stats: DayLog[];                         // өдрийн тайлангийн түүх
}

interface Animal {
  id: number; species: 'sheep'|'goat'|'cow'|'horse'; sex: 'm'|'f';
  ageCycles: number;        // хийсвэр нас (20 өдөр = 1)
  condition: number;        // тарга 0–1
  health: number;           // 0–100
  gutFill: number; dietQuality: number;    // өдрийн идэш
  thirst: number;
  lactating: boolean; cycleDay: number;    // төллөлтийн мөчлөг
  x: number; z: number; heading: number;
  herdId?: number; stallion?: boolean; riding?: boolean;
}
```

- **Бэлчээрийн тор:** 2 м нүдтэй, хэд хэдэн `Float32Array`-д хадгална (biomass, height, degrade, wolfRisk, type). 190 × 190 нүд нь 36 100 элемент бөгөөд санах ой бага.
- **Амьдын жин** хадгалагдахгүй, тооцоолно: `W = F(species, sex, age) × (0.75 + 0.4 × condition)` (`grazing-livestock.md` §1).

## 5. Дүрслэл

- **Мал:** төрөл бүрт нэг `InstancedMesh`. 1000 мал = цөөн draw call. Насаар хэмжээ, таргаар бүдүүн/нарийныг instance-ийн матрицаар өгнө.
- **Бэлчээр:** газрын vertex color эсвэл жижиг текстурыг өдөр бүр бэлчээрийн тороос шинэчилнэ. Талхлагдсан хэсэг шаргал, сайн бэлчээр ногоон харагдана.
- **Бүтээгдэхүүн:** газарт унасан сав, ноосыг жижиг дүрсээр харуулна. Хулганаар дарж эсвэл ойртож түүнэ. Муудах тусам өнгө нь өөрчлөгдөнө.
- **График:** прототипын low-poly хэв маяг хэвээр (хэрэглэгчийн шийдвэр: график, дууг хамгийн энгийн байлгах). Ард нь хөнгөн морин хуурын ая.

## 6. Хадгалалт

- Өдрийн эцэст автоматаар IndexedDB-д хадгална. 3 слот.
- Хадгалсан файл бүр `version` талбартай. Хувилбар өөрчлөгдөхөд шилжүүлэх функц (`migrations`) ажиллана.
- JSON файл болгон татаж авах, буцааж оруулах боломжтой. Алдаа илгээх, туршилтад хэрэгтэй.

## 7. Хэл

- Бүх текст түлхүүрээр (`product.aaruul`) `i18n/mn.json`, `i18n/en.json`-д хадгалагдана. Монгол хэл үндсэн.
- Монгол нэр томьёо (хурга, бууц, хот айл) англи хувилбарт монголоор нь үлдэж, хажууд нь тайлбар гарна. Гадаадын тоглогчид «өөр ертөнц» мэдрүүлэх зорилготой.
- Хуучин `docs/16_glossary.md`-ийн кодын нэршлийг ашиглана.

## 8. Тест ба тэнцвэр

| Төрөл | Юу шалгах |
|---|---|
| Нэгжийн тест (Vitest) | Систем бүр: өвсний ургалт, доройтол, тарга/жин, бүтээгдэхүүн муудах, агуулахын багтаамж, цалин, төллөлт |
| Тодорхой тоглолтын тест | Seed X, 30 өдөр, тодорхой командууд → мөнгө, малын тоо хүлээгдэж буй хязгаарт байх |
| Тэнцвэрийн симулятор | `tools/balance_sim`: олон seed × тоглогчийн стратеги (идэвхтэй, залхуу, туслахтай). Зорилгод хүрэх хугацаа, мөнгөний урсгалын тайлан |
| Гүйцэтгэл | 1000 малтай 1 өдөр 3D-гүйгээр < 50 мс. Дунд зэргийн компьютерт 60 FPS |
