# Техникийн архитектур (MVP «Зуслан»)

> Нүүдэлчин тоглоом. 2026-11-13, сүүлд шинэчилсэн 2026-11-14 (M5.5-ын байдлаар). Хөдөлгүүр: **TypeScript + Three.js** (хэрэглэгчийн шийдвэр).
> **Төлөв:** хүчинтэй. Энэ баримт нь хуучин [[13_technical]]-ийн хөдөлгүүр сонголтын хэсгийг орлоно. Тэр баримтын зарчмууд (өгөгдөлд тулгуурлах, симуляц ба дүрслэлийг салгах, seed) хэвээр хүчинтэй.
> Тоглоомын дүрэм: [[mvp-spec]] (давуу эрхтэй), [[grazing-livestock]], [[water-horses-transport]]. Үе шат бүрт нэмэгдсэн файлууд: [[milestones]]. Баримтын хөтөч: [[INDEX]].

## 3. Гол зарчмууд

### 3.1 Симуляц ба дүрслэл тусдаа

```
 Input ──Command──▶  sim (GameState-ийг өөрчлөх ганц газар)  ──Event──▶  UI / дуу
                              │
                              ▼ (уншина)
                           render (Three.js)
```

- `sim/` хавтас Three.js, DOM, `window`-г огт импортлохгүй. Тиймээс тест болон тэнцвэрийн симулятор 3D-гүйгээр ажиллана.
- `render/` зөвхөн GameState-ийг уншиж зурна. Тоглоомын логикийг `render/` дотор бичихгүй.
- Тоглогчийн бүх үйлдэл `Command` болж sim рүү очно. Ингэснээр тоглолтыг дахин тоглуулах (replay), тестлэх боломжтой.

### 3.2 Тогтмол алхамтай цаг

- Симуляцын нэг алхам = **1 тоглоомын минут.**
- 1× хурдаар өдөр 1 тоглоомын цаг = 10 сек, **шөнө 2 сек** (`data/time.json`, [[mvp-spec]] §2). Өдөр 1 алхам ≈ 0.167 сек. Бүтэн өдөр (06:00→06:00) ≈ 2.8 мин. Газрын зураг дээр Shift — ×8.
- Render нь секундэд 60 удаа зурж, хоёр алхмын хооронд байрлалыг зөөлрүүлнэ (interpolation).
- **Давтамж:**

| Хэзээ | Юу |
|---|---|
| Алхам бүр (1 мин) | Хөдөлгөөн, бэлчээрлэх, боловсруулалтын явц, чоно, тээвэр/газрын зураг дээр явах, туслахын үйлдэл |
| 10 алхам тутам | Малын бэлчээрийн цэг сонгох (оноо), сүргийн шийдвэр, туслахын шийдвэр |
| Цаг бүр | Сүүний муудах хугацаа, цангалт |
| 06:00 | Мал хоносон газраа сүү, ноос үлдээх (`night.ts → morning`) |
| 18:30–19:00 | Мал өөрсдөө хотлох |
| 20:00 | Тарга, жин, эрүүл мэнд, өвсний ургалт, бууцны доройтол, боодол өвс өгөх (өвөл/хавар), цалин (5 өдөр тутам), өдрийн тайлан, автомат хадгалалт (M6) |
| 21:00 | Шөнө: шөнийн чоно, хүйтэн (гадуур хоносон мал) |
| Өдөр бүр (улирлаар) | Цас орох/хайлах, улирал солигдох, төллөлт (`birthYearDay`), отрын бүтээгдэхүүн |
| Жил бүр (50 өдөр) | Нас ахих ([[mvp-spec]] §9) |

- **3D-гүй горим:** алхмуудыг хамгийн хурдан гүйлгэнэ. Зорилт: 1 тоглоомын өдөр 3D-гүйгээр < 50 мс (1000 малтай). Одоо ~200–300 мс ([[milestones]] «Эрсдэл»).

### 3.3 Давтагддаг санамсаргүй тоо

- `sim/` дотор `Math.random()` хэрэглэхгүй. Бүх санамсаргүй тоо `rng.ts`-ийн seed-тэй генератороос гарна.
- Нэг seed + нэг командын дараалал → яг ижил тоглолт. Алдаа давтан гаргах, тэнцвэр шалгахад чухал.
- Зарим систем (чоно, Цайны газрын нэр дэвшигч) өөрийн RNG-тэй тул тэнцвэрийн дүнг өөрчлөхгүй.

### 3.4 Өгөгдөлд тулгуурлах

Кодонд тоо шууд бичихгүй. Бүх утга `data/` хавтасны JSON файлд байна:

| Файл | Агуулга |
|---|---|
| `time.json` | Өдрийн эхлэл (06:00), тайлан, шөнө, цагийн урт (өдөр/шөнө), сарын урт, жилийн урт (`animalYearDays` = 50), газрын зургийн хурдасгал |
| `seasons.json` | Улирлын урт, өвс ургалт, цас, хүйтэн, шөнийн чоно (M5.5) |
| `animals.json` | Мал бүрийн жин, өсөлт, насны шат, төллөлтийн магадлал, цангалт, кг-ын үнэ |
| `pasture.json` | Бэлчээрийн төрөл, өвсний зүйл, улирлын чанар, ургалт, доройтол, сүргийн шийдвэр (`grazing.herd`) |
| `camps.json` | Бууцнууд (`river`, `northSlope`, `southSlope`, `valley`): бэлчээрийн хольц, ус, чонын эрсдэл, цас, саравч, газрын хэлбэр, хот (`home.cowYard`), зам (`road`) |
| `worldmap.json` | Газрын зураг: бууц ба сумын төвийн байрлал (км), хурд |
| `products.json` | Сүү, тараг, ноос, ноолуур: үйлдвэрлэл, муудах хугацаа, үнэ |
| `processing.json` | Тогоо, сепаратор, эсгий: оролт, гаралт, хугацаа, үнэ |
| `storage.json` | Агуулахын түвшин, багтаамж, үнэ |
| `vehicles.json` | Морин тэрэг, Портер, Амжиргаа цагаан: багтаамж, хурд, бензин, үнэ |
| `player.json` | Малчин, морь: хурд, айлгах зай, «Хөөе» радиус |
| `dogs.json` | Нохойн үнэ, хоол, командууд, хамгаалалтын бүс, сэлгүүцэх (`wander`, B4) |
| `helpers.json` | Туслахын үүрэг, цалин, айлын хөнгөлөлт, байр, Цайны газар, отор, малчны хуваарь (`herder.schedule`, B2), адуучны майхан (`herder.horseCamp`, B3) |
| `economy.json` | Эхлэлийн мөнгө, гэр, өдөр тутмын зардал, худалдан авах үржүүлэгч |

- Тэнцвэр тааруулахдаа зөвхөн JSON файлыг засна, кодод хүрэхгүй.

## 4. Өгөгдлийн загвар (товч)

Санаа өгөх зорилготой ноорог. Бодит төрлүүд `sim/state.ts`-д.

```ts
interface GameState {
  version: number;          // хадгалалтын хувилбар
  seed: number; rngState: number;
  time: { day: number; minute: number };   // өдөр 06:00-аас дараа өглөөний 06:00 хүртэл; улирал, жил day-ээс тооцогдоно
  money: number;
  campId: string;                          // 'river' | 'northSlope' | 'southSlope' | 'valley'
  camps: Record<string, CampState>;        // бууц бүрийн доройтол, ачаалал, цас, боодол өвсний овоо
  grass: GrassGrid;                        // одоогийн бууцны тор (Float32Array)
  animals: Animal[];
  items: GroundItem[];                     // газарт унасан бүтээгдэхүүн
  storage: { level: number; stock: Record<ProductId, Batch[]> };
  processors: ProcessorState[];
  fleet: VehicleState[];                   // тээвэр бүрийн байрлал, ачаа (M4.6)
  helpers: Helper[]; housing: Housing[];   // туслах, отор (M5)
  player: PlayerState;                     // place: camp | sum | map
  stats: DayLog[];                         // өдрийн тайлангийн түүх
}

interface Animal {
  id: number; species: 'sheep'|'goat'|'cow'|'horse'; sex: 'm'|'f';
  ageCycles: number;        // нас (1 = 50 өдрийн жил)
  condition: number;        // тарга 0–1
  health: number;           // 0–100
  gutFill: number; dietQuality: number;    // өдрийн идэш
  thirst: number;
  lactating: boolean;       // тухайн жил төллөсөн эсэх
  x: number; z: number; heading: number;
  herdId?: number; stallion?: boolean; riding?: boolean;   // + туслахын мал эсэх (M5)
}
```

- **Бэлчээрийн тор:** 2 м нүдтэй, хэд хэдэн `Float32Array`-д хадгална (biomass, height, degrade, wolfRisk, type). 190 × 190 нүд нь 36 100 элемент бөгөөд санах ой бага.
- **Амьдын жин** хадгалагдахгүй, тооцоолно: `W = F(species, sex, age) × (0.75 + 0.4 × condition)` ([[grazing-livestock]] §1).

## 5. Дүрслэл

- **Мал:** төрөл бүрт нэг `InstancedMesh`. Насаар хэмжээ, таргаар өргөн ба хонины өөхөн сүүлийг instance-ийн матрицаар өгнө. Туслахын мал төрөлх зүсээ хадгалж, нурууны тэмдгээр ялгарна.
- **Бэлчээр:** газрын vertex color-ийг бэлчээрийн тороос 0.4 сек тутам шинэчилнэ. Талхлагдсан хэсэг шаргал, сайн бэлчээр ногоон; намар шаргал, өвөл цастай.
- **Бүтээгдэхүүн:** газарт унасан сав, ноосыг жижиг дүрсээр харуулна. Ойртож түүнэ. Муудах тусам өнгө нь өөрчлөгдөнө.
- **Газрын зураг, сумын төв:** тусдаа 3D дүр зураг (`worldmap.ts`, `sumcenter.ts`).
- **График:** загварлаг low-poly хэв маяг; палитр, цаг/улирлын гэрэл, өвсний тоо `data/visuals.json`-д. `device.ts`-ийн `low`/`mid`/`high` түвшин, `?stats` хэмжилт, `?shot=1..7` хөрөг горимтой ([[visuals-plan]]). Дуу тусдаа MVP шийдвэр хэвээр.

## 6. Хадгалалт (M6)

**Дүрэм (M6.1):** тоглоомын БҮХ төлөв `GameState`-д (энгийн JSON: Map/Set/undefined/NaN үгүй). `Sim` ангид зөвхөн `cfg`-ээс дахин тооцогдох кэш (бэлчээрийн чанар) үлдэнэ. Бүх RNG-ийн төлөв state-д: `rngState` (команд бүрийн дараа ба алхам бүрийн төгсгөлд), `wolves.rngState`; өдөр тутмын туслахын RNG нь `seed`+өдрөөс гарна. Шинэ төлөв нэмбэл `SAVE_VERSION`-г ахиулж `MIGRATIONS`-д алхам бичнэ. `sim/save.ts`: `serialize`, `deserialize` (= задлах + `migrate` + `validateState`, алдаа → `SaveError`). **Хөтөч (M6.2, `persist/`):** слот бүрт A/B хуулбар — нэг гүйлгээнд хуучныг нь шинэчилнэ, бичих дундаа тасрахад нөгөө нь бүтэн (+ хэмжээ/FNV нийлбэр). Автомат хадгалалт sim-ийн алхмын ДУНД хийхгүй: үйл явдал (20:00 `dayReport`, `arrived`, `leftToMap`) → хүсэлт → кадрын давталт алхмуудын дараа `flush`; хуудас нуугдах/хаагдахад тэр дор. `.nuudel` = gzip(JSON). Гарах шалгуур: `tests/save.test.ts` — 15 өдөр + хадгалах + ачаалах + 15 өдөр нь 30 өдөр тасралтгүйтэй ижил (4 seed).

- Өдрийн эцэст автоматаар IndexedDB-д хадгална. 3 слот.
- Хадгалсан файл бүр `version` талбартай. Хувилбар өөрчлөгдөхөд шилжүүлэх функц (`migrations`) ажиллана.
- JSON файл болгон татаж авах, буцааж оруулах боломжтой. Алдаа илгээх, туршилтад хэрэгтэй.

## 7. Хэл

- Бүх текст түлхүүрээр (`product.aaruul`) `i18n/mn.json`, `i18n/en.json`-д хадгалагдана. Монгол хэл үндсэн. Англи хувилбар — M6.
- Монгол нэр томьёо (хурга, бууц, хот айл) англи хувилбарт монголоор нь үлдэж, хажууд нь тайлбар гарна. Гадаадын тоглогчид «өөр ертөнц» мэдрүүлэх зорилготой.
- Хуучин [[16_glossary]]-ийн кодын нэршлийг ашиглана. Бууцны id ба нэр: [[INDEX]] «Нэр томьёо».

## 9. Туршилтын цэс

G — бэлчээрийн дулааны зураг, Z — хамгаалалтын бүс.

## 10. Ажиллуулах

```bash
cd game
npm install      # анх нэг удаа
npm run dev      # хөтчид http://localhost:5173
npm test         # тест
npm run balance -- --seeds 12 --days 220   # тэнцвэрийн симулятор
npm run build    # dist/ (вэб хуудас болгон тавих)
```

Windows дээр Node.js 20+ суулгасан байх шаардлагатай.
