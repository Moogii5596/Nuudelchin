# Баримтын жагсаалт — Нүүдэлчин

> Монгол нүүдэлчин ахуйг харуулсан 3D тоглоом. **Хөдөөний амьдралд бүрэн автаж, тайвширч суух симулятор** — хожих, юм нээх нь гол биш, тоглоом дуусахгүй. Баримтын эх сурвалж = repo-ийн `docs/` (claude.ai Project «Монгол»-д давхар хадгалахгүй).

Шинэ баримт нэмэх, үе шат дуусах бүрт энэ файлыг шинэчилнэ ([[AGENTS]] §8, §12).

---

## 1. Унших дараалал ба давуу эрх

Ажлын эхэнд: [[AGENTS]] → [[CONTEXT]] → `PROGRESS.md` (одоогийн үе шат) → `docs/plan/<Mx>.md`. Үлдсэнийг зөвхөн хамаарах хэсгээр: `grep -n '<түлхүүр>' docs/CODEMAP.md` → `sed -n 'a,bp'`. `docs/v1/`, `docs/_archive/`-г ажлын үед уншихгүй.

Зөрчилдвөл дээд нь хүчинтэй:

1. **[[mvp-spec]]** — MVP-ийн нэгдсэн дүрэм. Шийдвэрийн түүх, нээлттэй шийдвэр → [[decisions]].
2. **`docs/plan/`** (одоогийн төлөвлөгөө), **[[architecture]]**, **[[milestones]]** (үе шат, гарах шалгуур).
3. **Үе шатын тэмдэглэл** — [[night-transport]] (M4.5), [[world-map-mvp]] (M4.6), [[helpers-m5]] (M5), [[seasons-camps]] (M5.5); **[[visuals-plan]]** (V0–V5).
4. **Дизайны суурь** — [[grazing-livestock]], [[water-horses-transport]].
5. **Түүх** — `docs/_archive/` (хуучин утгатай, лавлагаа), [[CHANGELOG]].
6. **V1+ дизайн** — `docs/v1/` (MVP-ийн дараа).

Баримт бүрийн frontmatter-д `status` бий (Draft | Active | Deprecated | Archived). Хуучирсан хэсэг ⚠ эсвэл ~~зураастай~~, юугаар солигдсоныг заасан.

## 5. Баримт засах дүрэм

- Шинэ шийдвэр гарвал: [[decisions]] §0-д огноотой нэмж, [[mvp-spec]]-ийн холбогдох хэсгийг засна; хуучирсан дүрэмд ⚠ эсвэл ~~зураас~~ тавьж шинэ газар руу заана.
- Нээлттэй асуултыг зөвхөн [[decisions]] §13–14-д жагсаана (гараар шалгах нь [[playtest]]); бусад баримт тийш заана.
- Явц зөвхөн `docs/plan/<Mx>.md`-д. Үе шат дуусахад [[CHANGELOG]], энэ INDEX, [[milestones]]-ийг шинэчилнэ.
- Тоон утгыг кодонд биш `data/*.json`-д ([[architecture]] §3.4). Холбоос `[[filename]]` хэлбэртэй; шинэ файлыг энд нэмнэ.
