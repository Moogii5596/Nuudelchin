# UI handoff 1 — Үндсэн мэню, тохиргоо (хэвтээ)

Төлөв: ✅ батлагдсан 2026-11-17 (хэрэглэгч «саналаар батлав»). Загвар: Design canvas «Нүүдэлчин — UI загвар 1» (Main = мэню, settings-c = тохиргоо, rotate = босоо дэлгэц).

## 0. Шийдвэр
- Утсан дээр **зөвхөн хэвтээ**. Босоо байрлалд зөвхөн «Төхөөрөмжөө хэвтээ болго / Rotate your device» дэлгэц. Босоо урсгал хийхгүй.
- Утасны суурь хэмжээ 844×390 CSS px (дэмжих муж 800–932 × 360–430). Комп (16:9) дээр ижил бүтэц, масштаблана.
- Safe-area: зүүн, баруун 48 px (хамгийн багадаа; `max(48px, env(safe-area-inset-left/right))`), дээд, доод 24 px.
- Анхдагч хэл англи; хос хэл (EN · MN) бүх товчинд хоёр мөр. Монгол орчуулга урт байж болно — товч мөр нугалж өндөр нэмнэ, өргөн тогтмол.
- Шилжүүлэх код формат `XXXX-XXXX`. «Санал илгээх» = тоглоом доторх жижиг форм (🙋 хэрэгжүүлэхдээ ахлах батална).

## 2. Мэню (844×390)
Бүтэц: 2 багана, padding 24 48. Зүүн 280 px: «Nuudelchin / Нүүдэлчин» (Noto Serif 40/20), 72×2 px accent зураас, тайлбар «Тайван тоглоорой…» 15 px, доор «v0.1 · MVP» ба «Могод сум». Баруун (flex 1): 4 карт, gap 10, tо тус бүр min-height 68, padding 8 16:
1. **Continue · Үргэлжлүүлэх** — зүүн 6 px accent тууз. Хадгалсан тоглолт байхгүй бол **disabled** (доорх төлөв), анхдагч фокус энд.
2. **New game · Шинээр эхлэх** — «Өвлийн бэлтгэлээс эхэлнэ». Хадгалсан тоглолттой бол товшихоор баталгаажуулах цонх (1 өгүүлбэр, «Хуучин тоглолт арилна», хоёр товч); шийтгэл, тоолуур байхгүй.
3. **Settings · Тохиргоо** → тохиргооны дэлгэц.
4. **Feedback · Санал илгээх** → жижиг форм.

Төлөв (мэнюгийн карт): default (card, border) · hover/focus (комп; border #9C4D25, focus ring 2 px #9C4D25 offset 2) · pressed (суурь #F0E4CC) · disabled (суурь #E9DCC4, текст #5B4632, зүүн тууз #C9B593, `aria-disabled`). Алдаа төлөв байхгүй (хадгалалт уншигдахгүй бол «Хадгалсан тоглолт уншигдсангүй» warn хайрцаг картын доор).

## 3. Тохиргоо (844×390)
Бүтэц: толгой 48 px (Back 44×44 + «Settings · Тохиргоо» Noto Serif 22), доор 2 багана (flex 1, gap 16), padding 12 48 16.

Зүүн багана (gap 10):
- **Хэл:** карт, шошго 100 px + 2 товч (English / Монгол), өндөр 48, `role=radio`. Сонгосон: 2 px accent хүрээ + «✓». Солих үед UI шууд солигдоно.
- **Дуу:** шошго + slider (өндөр 48, accent #9C4D25), утга 0–100, анхдагч 70. Морин хуур/орчны дууны тусдаа унтраалга энэ MVP-д шаардлагагүй (дуу нэг slider).
- **Дүрсний чанар:** 3 товч grid (Low · Бага / Mid · Дунд / High · Өндөр), өндөр 56, тайлбар 13 px. Анхдагч: утсанд Mid. Draw call хязгаар: утсанд ≤ 120 ([[decisions]] 11-16).

Баруун багана (gap 10):
- **Шилжүүлэх код:** карт. Мөр 1: өөрийн код (mono 22 / 700, letter-spacing 2) + «Copy · Хуулах» (44 өндөр, outline). Мөр 2: оруулах талбар (48, border 2 px) + «Apply». Мөр 3: warn/алдааны мөр.
- **Feedback · Санал илгээх:** өндөр 56 карт-товч, баруун тал сумтай.

## 4. Босоо байрлал
Бүтэн дэлгэц, суурь #2B2118, текст #F6EFE2 / #CDBFA6, утасны дүрс (#E0B07A), «Төхөөрөмжөө хэвтээ болго» (Noto Serif 26) + «Rotate your device». Тоглоомыг түр зогсооно (sim үргэлжилнэ гэж гэмтээхгүй: орчинг хэвтээ болмогц буцаана).

## 5. Хөгжүүлэгчид
- Бүрэлдэхүүн: `MenuScreen`, `SettingsScreen`, `RotateGate`, `SegmentedChoice`, `VolumeSlider`, `TransferCodeCard`, `FeedbackSheet`.
- Орчуулга: `i18n` түлхүүр бүрт en, mn; товчны өргөн тогтмол, текст нугалж өндөр нэмнэ.
- Хандалт: бүх товч жинхэнэ `<button>`, фокус ring харагдана, `role=radio`/`slider`, `aria-label` (Back, Copy).
