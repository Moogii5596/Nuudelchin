# V0–V5: дүрслэлийг дуусгах

Дизайн, хэв маяг, чанарын түвшин, хөрөг цэгүүд: [[visuals-plan]]. Дараагийн үе шат: [[M6]]. Хэрэглэгч гараар шалгах зүйлс: [[playtest]]. **Явц зөвхөн энэ файлд тэмдэглэгдэнэ.**

## Зорилго
V0–V5 дүрслэлийг бүтнээр нь дуусгаж (хэрэглэгчийн шийдвэр 2026-11-15, [[decisions]] §0), дараа нь M6. Утсан дээр (Samsung Galaxy S25, `low`) 300 малтай 30+ FPS, компьютер 60 FPS (D6) хэвээр байна.

## Гарах шалгуур ([[visuals-plan]] §V3–V5, §7.1)
- Хөрөг 1, 4, 6-д гэр «Монгол гэр» гэж танигдана (хэрэглэгч батална).
- Хөрөг 1, 2-т малын төрөл, зүс, нас, туслахын мал ялгарна; 1000 мал `high`-д 60 FPS.
- 7 хөрөг зураг «дараа» төлөвт; §7.1-ийн хязгаар хангагдсан; хэрэглэгч батална.

## Блокууд ба чеклист (2026-11-15)
Нэг файлд нэг агент. Өөр файлтай блокууд зэрэг явна. Тест: `npx vitest run tests/style.test.ts --reporter=dot` (визуал тохиргооны шалгалт), блокийн төгсгөлд бүтэн `npm test` + `npm run build`. Блок бүр: sim (хамаарвал) → `data/*.json` → render → UI → i18n → тест → docs.

✅ = код эсвэл шийдвэр баталгаажсан; ⏳ = ажил/баталгаажуулалт үлдсэн. Код хэрэгжсэн байх нь төхөөрөмжийн хэмжилт, хэрэглэгчийн зөвшөөрлийг автоматаар хаахгүй.
