# M6: хадгалалт, замын тэмдэгтүүд, тэнцвэр, англи хэл

Эхлэх нөхцөл: [[V]] (дүрслэл) дуусна. Дүрэм: [[mvp-spec]] (давуу эрхтэй, §10 — тайван симулятор, тоглоом дуусахгүй). Хадгалалтын архитектур: [[architecture]] §6, §11. Дараагийн үе шат: [[M7]]. Үе шатны хураангуй: [[milestones]]. Шийдвэр: [[decisions]] §0 (MVP-ийн хүрээ хаагдсан 2026-11-15).
Тэмдэглэгээ: 🧑 хэрэглэгч өөрөө хийх алхам, 🤖 агент.

**Feature freeze:** M6 эхэлснээс хойш шинэ механик нэмэхгүй; шинэ санааг [[mvp-spec]] §1-ийн «Хойшилсон» багананд бичнэ. Үл хамаарах: өрсөлдөгчийн судалгааны шийдвэрээр (2026-11-15, [[decisions]] §0) freeze-ээс өмнө орсон жижиг функцүүд M6.8–M6.12, гэрийн систем M6.13 (2026-11-15).

## Зорилго
Тоглолт алдагдахгүй хадгалагдаж, утас ↔ компьютер хооронд шилжинэ; олон давхар замын тэмдэгтүүд, урт зам ба «гэр оронтой болсон» мөч; «тогтвортой амьдрах» тэнцвэр (өдөр 5–6 мин); тайван тохиргоо; мал гацахгүй, амьд санагдах; утсанд тохирсон туух; монгол + англи хэл.
