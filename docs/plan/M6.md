# M6: хадгалалт, замын тэмдэгтүүд, тэнцвэр, англи хэл

Эхлэх нөхцөл: [[V]] (дүрслэл) дуусна. Дүрэм: [[mvp-spec]] (давуу эрхтэй, §10 — тайван симулятор, тоглоом дуусахгүй). Хадгалалтын архитектур: [[architecture]] §6, §11. Дараагийн үе шат: [[M7]]. Үе шатны хураангуй: [[milestones]]. Шийдвэр: [[decisions]] §13–14.
Тэмдэглэгээ: 🙋 хэрэглэгчийн шийдвэр, 🧑 хэрэглэгч өөрөө хийх алхам, 🤖 агент.

**Feature freeze:** M6 эхэлснээс хойш шинэ механик нэмэхгүй; шинэ санааг [[mvp-spec]] §1-ийн «Хойшилсон» багананд бичнэ.

## Зорилго
Тоглолт алдагдахгүй хадгалагдаж, утас ↔ компьютер хооронд шилжинэ; замын тэмдэгтүүд ба «гэр оронтой болсон» мөч; «тогтвортой амьдрах» тэнцвэр; монгол + англи хэл.
