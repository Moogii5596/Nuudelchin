# Ахлах хөгжүүлэгчийн дамжуулах тэмдэглэл

Шинэ ахлах чат **энэ файлыг** + [[AGENTS]] + [[BOARD]]-ыг уншаад үргэлжилнэ. Нээлттэй ажил, агентын бүртгэл, давалгаа зөвхөн [[BOARD]]-д (энд давхар хуулахгүй).

## A. Тогтвортой (ховор өөрчлөгдөнө)

### Ажлын загвар
- **Ахлах чат (claude.ai):** BOARD-ын карт бичнэ, тайлан шалгана, шийдвэрийг хэрэглэгчээс асууна; зөвхөн ахлах `BOARD.md`-д бичнэ. Зураг үзэхгүй (хэрэглэгч `tools/shots/`-ийг өөрөө харж батална).
- **Агент (Claude Code, VS Code):** `Агент N: BOARD T-xx` гэсэн заавраар ажиллана. Агент бүр өөрийн worktree + салбарт (`../wt-<нэр>`, `feat/<нэр>`), зөвхөн карт дээрх «Файл»-д хүрнэ. Нэг файл = нэг агент.
- **Нэгтгэгч (Агент 1):** давалгааны төгсгөлд merge, `npm run codemap`, бүтэн тест, build, push (хэрэглэгчийн зөвшөөрлөөр).
- **Загвар батлах:** лаборатори (`tools/character-lab/`, `http://localhost:5199/...`) → зураг `tools/shots/<сэдэв>/` → хэрэглэгч батлах → өөр агент тоглоомд оруулна.
- **Хэрэглэгчийн суурь шийдвэр:** анхдагч хэл АНГЛИ (`dca7e7f`); зорилго = том гэр (5+ ханат) + 40 хонин толгой; эхлэл бага 4 ханат гэр; MVP дуугүй, feature freeze.

### Тайлангийн бүтэц
Монгол хэлээр, товч (≤ 8–12 мөр): юу хийсэн · `T-xx ✅ <commit>` · баталгаажсан эсэх (тест, build) · өөрчилсөн файл · бусад агенттай хөндлөн холбоо · хэрэглэгчийн шийдэх зүйл · анхааруулга ([[AGENTS]] §13, §15).

### Нэршил
- Агент = дугаар (1, 2, 3…); карт `T-xx` (агент), `U-x` (хэрэглэгч); салбар `feat/<нэр>`; worktree `../wt-<нэр>`.
- Коммитын гарчиг англи, `git add` файлыг нэрээр; `push`, `tag`, устгал хэрэглэгчийн зөвшөөрлөөр.
- Баримтын холбоос `[[нэр]]`; шинэ файл [[INDEX]]-д.

### Контекст хэмнэх
Ахлах чатыг урт болгохгүй: том ажлын дараа энэ файл, [[BOARD]]-ыг шинэчилж шинэ чат нээнэ. Энгийн ажил Sonnet, нарийн архитектур Opus. Нэг даалгавар = нэг session.
