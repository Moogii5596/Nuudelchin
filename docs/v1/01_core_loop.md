# 01. Тоглоомын давталт, цаг, хүч

## 1. Гурван түвшний давталт

```
┌─────────────────────────────────────────────────────────┐
│ ЖИЛ (4 улирал)                                          │
│  Төллөх → бойжуулах → таргалуулах → өвөлжих             │
│  Мал өсгөх, гэр бүл, цол, Наадам                        │
│  ┌───────────────────────────────────────────────────┐  │
│  │ УЛИРАЛ (20 өдөр)                                  │  │
│  │  Бууцанд буух → ашиглах → бэлтгэх → НҮҮХ          │  │
│  │  ┌─────────────────────────────────────────────┐  │  │
│  │  │ ӨДӨР                                        │  │  │
│  │  │  Саах → гаргах → боловсруулах → зарах →     │  │  │
│  │  │  хураах → хоол → унтах                      │  │  │
│  │  └─────────────────────────────────────────────┘  │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
```

### 1.1. Өдрийн давталт
1. **Өглөө (06:00–09:00):** Үнээ, гүү саах. Цайгаа чанаж дээж өргөх. Малаа бэлчээрт гаргах.
2. **Өдөр (09:00–17:00):** Сүү боловсруулах, аргал түүх, ус зөөх, зах явах, хашаа засах, морь сургах, хөршөөр орох.
3. **Орой (17:00–21:00):** Малаа хураах, тоолох, оройн сааль, хоол.
4. **Шөнө (21:00–06:00):** Унтах. Чоно ирж магадгүй, нохой хамгаалалт хэрэгтэй.

### 1.2. Улирлын давталт
1. Шинэ бууцанд буух: гэр, хашаа барих.
2. Бууцны давуу талыг ашиглах: зун сүү, намар тарга, өвөл хамгаалалт, хавар төл.
3. Дараагийн улиралд бэлтгэх: мөнгө, тэжээл, өвс, тээвэр.
4. Нүүдлийн цонхонд нүүх ([05_migration.md](05_migration.md)).

### 1.3. Жилийн давталт
- **Хавар:** Төллөлт, сүргийн тоо өснө.
- **Зун:** Сүүний оргил, Наадам, ноос хяргах.
- **Намар:** Таргалалт, зарах хамгийн сайн үе, идэш гаргах, хээлтүүлэг.
- **Өвөл:** Хамгаалалт, нөөцөө зарцуулах, Цагаан сарын бэлтгэл.

### 1.4. Хоёр давхар тоглолт
Mount & Blade маягаар тоглоом хоёр давхаргатай ([11_world_weather.md](11_world_weather.md) §1):
- **Их газрын зураг:** Нүүдэл, зах явах, наадам, айлд зочлох, отор. Чөлөөтэй явна.
- **3D бууц:** Мал хариулах, саах, үйлдвэрлэл, гэр барих. Дээрх өдрийн давталт энд явагдана.

## 2. Цаг

| Нэгж | Утга | Тэмдэглэл |
|---|---|---|
| 1 тоглоомын өдөр (3D бууц) | ≈ 12 бодит минут | Тохиргоогоор 8–20 минут болгож болно |
| 1 тоглоомын өдөр (их газрын зураг) | ≈ 40 бодит секунд | Аялал хурдан явагдана |
| 1 улирал | 20 өдөр | |
| 1 жил | 4 улирал = 80 өдөр ≈ 16 цаг | |
| Тоглоомын эхлэл | **Зун, 1 дэх өдөр**, сонгосон багийн зуслан | Хамгийн зөөлөн улирлаас эхэлнэ. Эхлэх мал бүсээс хамаарна ([11](11_world_weather.md) §4.2) |

Унтах үед цаг шууд өглөө рүү шилжинэ. Нүүдлийн аялал нь цаг хурдасгасан горимоор явна.

## 3. Хүч ба Цадалт

### 3.1. Хүч (Energy)
- Дээд хэмжээ: **100**
- Унтаж нөхөгдөнө: майханд +80, гэрт +100.
- Хүч 0 болбол дүр ядарч ухаан алдаж, дараагийн өглөө 50 хүчтэй сэрнэ.

### 3.2. Цадалт (Hunger)
- 0–100. Өдөрт 30 буурна.
- Хоол идэж нөхнө: цай, сүү +10; хуушуур, шөл +30; чанасан мах +40.
- Цадалт 0 бол хүчний дээд хэмжээ 50% болно.

### 3.3. Ажлын хүчний зардал

| Ажил | Хүч | Хөнгөлөх арга |
|---|---|---|
| Үнээ саах | 4 / толгой | Эхнэр (сүүний эзэгтэй), туслах |
| Гүү саах | 3 / толгой | |
| Мал гаргах, хураах | 15 / өдөр | Хоточ нохой: 5, явганаар: 30 |
| Сүү боловсруулах | 5–10 / багц | Эхнэр |
| Аргал түүх (1 өдрийн түлш) | 10 | Нөөцөлж болно |
| Ус зөөх | 10 | Голын эрэг ба худагтай: 5 |
| Хоол хийх | 5 | |
| Сумын төв явах (морь, тэмээтэй) | 30 + хагас өдөр | Мотоцикл: 10 |
| Ноос хяргах | 3 / хонь | |
| Мал эмчлэх | 5 / толгой | Эхнэр (малын эмч) |
| Майхан барих / буулгах | 10 | |
| Гэр барих / буулгах | 40 | 2 хүн бол хүн бүр 20 |
| Хашаа засах | 20 | |

**Тэнцвэрийн санаа:** Эхлэлд (2 үнээ, 10 хонь) өдрийн ажил ≈ 60 хүч зарцуулна. Мал өсөх тусам хүч хүрэлцэхгүй болно. Энэ нь нохой, эхнэр, туслах, машин зэрэг худалдан авалт бүрийг утга учиртай болгоно.

## 4. Хүнсний хэрэгцээ

Хүнс нь **өөрийн малаас** эсвэл **худалдаж** авна.

| Хүнс | Эх үүсвэр | Тэмдэглэл |
|---|---|---|
| Сүү, цай | Өөрийн сааль | Үнэгүй, зарах сүүнээс хасагдана |
| Цагаан идээ | Өөрийн боловсруулалт | |
| Мах | Мал гаргах | 1 хонь ≈ 1 хүний 30 өдрийн мах |
| Гурил, будаа, цайны навч, давс | Дэлгүүр | ≈ 3,000₮ / хүн / өдөр |

**Идэш гаргах (намар):** Намрын тарган малаас өвлийн махаа бэлтгэнэ. Нэг удаа хийгээд зоорь эсвэл агуулахад хадгална. Хүнсний зардал өвөл хэмнэгдэнэ.

## 5. Тоглогчийн үндсэн үйлдлүүд

- Явах, морь унах, мотоцикл, машин жолоодох
- Малд хандах: саах, эмчлэх, тэжээх, зарах, сонгох
- Сүрэгт тушаал өгөх: гаргах, хураах, тодорхой газар руу туух
- Уурга шидэх: адуу барих
- Барих: майхан, гэр, хашаа
- Боловсруулах: хэрэгсэлтэй харилцах
- Худалдаа: зах, хөрш, дэлгүүр
- Харилцаа: NPC-тэй ярих, бэлэг өгөх, ёс заншлын үйлдэл
