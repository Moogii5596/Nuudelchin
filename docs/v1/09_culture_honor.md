# 09. Соёл, ёс заншил, хүндлэл

> **Зарчим:** Ёс заншлыг лекц уншиж заахгүй. Тоглогч үйлдлээрээ мэдэрч сурна. Монгол ахуйг хүндэтгэлтэй, үнэн зөв дүрсэлнэ.

## 1. Хүндлэл систем

### 1.1. Үзүүлэлт
Mount & Blade-ийн «харилцаа + алдар» загвартай төстэй хоёр түвшинтэй:

| Үзүүлэлт | Хүрээ | Хамрах хүрээ | Юунаас өснө |
|---|---|---|---|
| **Хүндлэл** | 0–100, эхлэл 20 | **Сум бүрт тусдаа** | Тухайн сумын айлуудтай харилцах, ёс заншил, тусламж |
| **Алдар** | 0–1000, эхлэл 0 | Улсын хэмжээнд | Наадмын амжилт, цол, амжилтууд, хотын гэрээ |

- Хүндлэл нь тухайн сумын NPC-ийн эхлэх харилцаа, нээгдэх үйлчилгээ (зээл, отор, хот айл)-нд нөлөөлнө.
- Алдар нь өөр сумын хүмүүсийн анхны хандлага (+0–20 хүндлэлийн урамшуулал), нийслэлийн гэрээ, цолд нөлөөлнө.
- Нутаг сэлгэхэд хүндлэл шинэ суманд 20 + алдрын урамшууллаас эхэлнэ ([11](11_world_weather.md) §5.2).
- Доорх хүснэгтүүдийн «Хүндлэл» гэдэг нь тоглогчийн одоо байгаа сумын хүндлэл.

| Хүндлэл | Нэр томьёо | Нөлөө |
|---|---|---|
| 0–19 | Танихгүй | Хөршүүд хүйтэн хандана, ×0.9 үнэ |
| 20–39 | Шинэ айл | Энгийн харилцаа |
| 40–59 | Найдвартай айл | Зээл, эхнэр сонгох эрх |
| 60–79 | Хүндтэй айл | Хот айл, отрын бэлчээрийн давуу эрх, ×1.05 үнэ |
| 80–100 | Нутгийн түшиг | Наадамд хүндэт зочин, бүх үйлчилгээнд хөнгөлөлт |

### 1.2. Хүндлэл нэмэх үйлдэл

| Үйлдэл | Хүндлэл |
|---|---|
| Өглөө цайны дээж өргөх | +1 / өдөр (өдөрт дээд тал нь 1) |
| Зочинд цай, идээ барих | +2 |
| Айлд ороход нар зөв эргэж, хүндэтгэлтэй байх | +1 |
| Хадаг барьж мэндлэх (ёслолын үеэр) | +3 |
| Хуучин бууцаа цэвэрлэх | +3 |
| Хөршид туслах (гэр барих, мал олох) | +5 |
| Цагаан сарын золголт | +2 / айл |
| Овоо тахилгад оролцох | +5 |
| Наадамд оролцох | +3 |
| Мал, морио сайн арчлах | +1 / улирал |
| Бэлчээрээ доройтуулахгүй байх | +5 / жил |

### 1.3. Цээрлэх зүйл (хүндлэл бууруулах)

| Үйлдэл | Хүндлэл | Тоглоомд хэрхэн илэрхийлэгдэх |
|---|---|---|
| Босгон дээр гишгэх | −3 | Гэрийн эзэн дуу алдаж, «Хүү минь, босго дээр гишгэдэггүй юм» гэнэ |
| Гал руу хог, бохир юм хаях | −5 | |
| Ус (гол, булаг) бохирдуулах | −5 | |
| Гэрт нар буруу эргэх | −1 | |
| Хойморт хүндлэлгүй суух | −1 | |
| Зочинд цай барихгүй байх | −3 | |
| Зээлээ буцааж өгөхгүй | −15 | |
| Бууцаа бохир орхих | −5 | |
| Морио зодох | −3 | |

**Анхны алдаа:** Тоглогч цээрлэх зүйлийг анх удаа гаргахад хүндлэл хасагдахгүй. Харин NPC зөөлөн тайлбарлаж, «Өвөөгийн сургаал»-д бүртгэгдэнэ. Хоёр дахь удаагаас хасагдана.

## 2. Өвөөгийн сургаал (кодекс)

Ёс заншил, малчны ухаан, зүйр цэцэн үгийн цуглуулга. Сурсан сургаал бүр:
- Тайлбар, түүхийн жижиг хэсэгтэй.
- Тоглоомд жижиг давуу тал өгнө.

| Сургаал (жишээ) | Хэрхэн сурах | Давуу тал |
|---|---|---|
| Шуурганы шинж | Анхны шуургыг даван туулах | Шуурганаас 1 өдрийн өмнө анхааруулга |
| Малын зан | 100 удаа мал хураах | Төөрсөн малын байршил газрын зураг дээр |
| Тэнгэр харах | Шөнө оддыг харах | Цаг агаарын урьдчилсан мэдээ 3 өдөр |
| Бэлчээр унших | Бүх 4 бууцанд цагтаа буух | Бэлчээрийн чанар газрын зураг дээр |
| Айлын ёс | 10 айлаар хүндэтгэлтэй орох | Шинэ NPC-ийн эхлэх харилцаа +10 |

> **Агуулгын эх сурвалж:** Зүйр цэцэн үг, ёс заншлын тайлбарыг угсаатны зүйч, соёл судлаачаар хянуулна ([15](15_decisions_open_questions.md)).

## 3. Баяр ёслол (тоглоомын хуанли)

| Үйл явдал | Хэзээ | Тоглоомд |
|---|---|---|
| **Битүүлэг** | Өвөл, 20 дахь өдөр | Гэр цэвэрлэх, битүүлгийн ширээ засах, бууз чимхэх |
| **Цагаан сар (Шинийн нэгэн)** | Хавар, 1 дэх өдөр | Ахмадаас эхлэн золгох, цагаан идээ, ууц тавих, айлаар орох |
| **Цагаан сарын уралдаан** | Хавар, 3 дахь өдөр | Морины уралдаан ([06_horses.md](06_horses.md)) |
| **Овоо тахилга** | Зун, 3 дахь өдөр | Овоог нар зөв гурав тойрч чулуу нэмэх, сүү цацах, бага наадам |
| **Наадам (сум, аймаг, улс)** | Зун, 2–6 (сум бүр өөр өдөр) / 8–9 / 11–13 дахь өдөр | Бөх, морь эсвэл тэмээн уралдаан, сур харваа, шагай харваа. Нийслэлд Улсын баяр наадам |
| **Тэмээний баяр** | Өвөл, 12 дахь өдөр, Говь аймгийн төв | Тэмээн уралдаан, тэмээн поло, гоёлын уралдаан ([06](06_horses.md) §9) |
| **Ноос хяргах өдөр** | Зун | Хөршүүд нэгдэж хамтдаа хяргана (хамтын ажил) |
| **Эсгий хийх** | Намар | Хамтын ажил, гар урлал |
| **Идэш гаргах** | Намар, 15 дахь өдөр орчим | Өвлийн махны бэлтгэл |
| **Гал тахих** | Өвөл, 10 дахь өдөр | Голомтоо тахих, гэр бүлийн аз жаргал |
| **Хурим** | Тоглогчийн сонголтоор | [07_family_npc.md](07_family_npc.md) |

> Баярын огноо нь тоглоомын хуанлид тохируулсан хялбаршуулсан хувилбар. Цагаан сар бодит амьдралд билгийн тооллоор жил бүр өөр өдөр болдог.

### 3.1. Цагаан сарын тоглолт
1. **Битүүлгийн өмнө:** Бууз чимхэх (мини тоглоом), цагаан идээ бэлтгэх, ууц чанах, шинэ дээл.
2. **Битүүлэг:** Гэр бүлээрээ ширээний ард.
3. **Шинийн нэгэн:** Өглөө эрт гарч, хадаг барьж, ахмадаас эхлэн золгоно.
4. **Айлаар орох:** Айл бүрт мэндчилж, бэлэг солилцоно.

## 4. Мини тоглоомууд

| Мини тоглоом | Хэзээ | Механик | Шагнал |
|---|---|---|---|
| 🤼 **Бөх** | Наадам | Тохиромжтой цагт товч дарах (барьц, мэх) | Шагнал, хүндлэл |
| 🏹 **Сур харваа** | Наадам | Салхи тооцож онох | Шагнал |
| 🦴 **Шагай харваа** | Наадам, өвөл | Хурууны хүч, чиглэл | Шагнал, хүндлэл |
| 🦴 **Шагай мэргэлэх** | Цагаан сар | Санамсаргүй 4 шагай: морь, тэмээ, хонь, ямаа | Өдрийн «аз» (жижиг бонус) |
| 🐪 **Ингэ хөөслөх** | Хавар | Ботгоо голсон ингэд хөөсний аялгууг хэмнэлтэй дуулах | Ингэ ботгоо хүлээн авна |
| 🐑 **Тойглох** | Хавар | Хурга голсон хонинд уламжлалт аялгууг давтах | Хонь хургаа хүлээн авна |
| 🪢 **Уурга шидэх** | Хүссэн үедээ | Морь давхиулж байх зуураа онох | Адуу барих |
| 🥟 **Бууз чимхэх** | Цагаан сар | Хээ зөв чимхэх | Чанар, хүндлэл |
| 🥛 **Айраг бүлэх** | Зун | Тогтвортой хэмнэл | Айрагны чанар |

> Ингэ хөөслөх, тойглох мини тоглоомын аялгууг ардын дуучнаар шинээр бичүүлж, зохиогчийн эрхийн асуудалгүй болгоно.

## 5. Гэрийн ёс

Гэрийн дотор зай бүр утгатай. Тоглогч гэр байрлуулахдаа уламжлалт байршлыг дагавал хүндлэл, тав тух нэмэгдэнэ:

| Зай | Утга | Байрлуулах зүйл |
|---|---|---|
| Хаалга | Урд зүгт харна | |
| Хоймор | Хаалганы эсрэг, хүндэт зай | Шүтээн, хүндтэй зочин |
| Баруун тал (эрэгтэй тал) | Эрэгтэйн эд зүйл | Эмээл, уурга, айрагны хөхүүр |
| Зүүн тал (эмэгтэй тал) | Гэрийн эзэгтэйн эд зүйл | Тогоо, сав суулга |
| Голомт | Гэрийн төв, ариун | Зуух |

> Гэрийн доторх эд зүйлийн уламжлалт байршлыг мэргэжилтнээр баталгаажуулна.

## 6. Төлөөлөл ба хүндэтгэл

- Ёс заншлыг шоглох, хуурамчаар дүрслэхгүй.
- Шашин шүтлэгийн зан үйлийг ерөнхий, хүндэтгэлтэй байдлаар харуулна.
- Хувцас, гэр, багаж хэрэгслийн дизайныг музейн цуглуулга, угсаатны зүйн материалд тулгуурлана.
- Хөгжүүлэлтийн явцад соёлын зөвлөх оролцуулна.
