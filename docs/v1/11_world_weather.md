# 11. Ертөнц: газрын зураг, бүс нутаг, цаг агаар

## 1. Хоёр давхар тоглолт (Mount & Blade маягаар)

Тоглоом хоёр давхаргаас бүрдэнэ:

| Давхарга | Хэзээ | Юу хийх | Цагийн хурд |
|---|---|---|---|
| 🗺️ **Их газрын зураг** | Нүүдэл, зах явах, айлд зочлох, наадамд очих, отор | Цуваа (тоглогч + сүрэг/ачаа) газрын зураг дээр чөлөөтэй явна. Сум, аймаг, нийслэл, бууц зэрэг цэгүүд руу орно | Хурдан: 1 тоглоомын өдөр ≈ 40 бодит секунд |
| 🏕️ **3D бууц** | Мал хариулах, саах, үйлдвэрлэл, гэр барих | Бууцандаа ирэхэд 3D орчин руу шилжинэ | Удаан: 1 тоглоомын өдөр ≈ 12 бодит минут |
| 🏘️ **Хот, сумын цэс** | Сумын төв, аймгийн төв, нийслэлд орох | Цэс хэлбэрийн дэлгэц: зах, дэлгүүр, малын эмч, наадам, NPC | Цаг бараг зогсоно |

```
   ┌─────────────────────── ИХ ГАЗРЫН ЗУРАГ ───────────────────────┐
   │  [Бууц] ──нүүдэл──► [Бууц]       [Сумын төв] ─► цэс           │
   │     │                               │                         │
   │     ▼                           [Аймгийн төв] ─► цэс          │
   │  3D БУУЦ (мал, сааль,               │                         │
   │  үйлдвэрлэл, гэр)              [Нийслэл] ─► цэс               │
   └───────────────────────────────────────────────────────────────┘
```

> Сум, аймаг, нийслэлийг MVP-д цэсээр хийнэ. 3D хот дотор алхах нь хожмын санаа ([15](15_decisions_open_questions.md)).

## 2. Газрын зургийн бүтэц

### 2.1. Шатлал

```
Улс
 ├── Нийслэл хот (1)
 ├── Хангай аймаг  ── аймгийн төв + 5 сум
 └── Говь аймаг    ── аймгийн төв + 5 сум
                         └── Сум ── сумын төв + 4 баг
                                       └── Баг ── 4 бууц (зуслан, намаржаа, өвөлжөө, хаваржаа)
```

| Нэгж | Тоо | Тоглоомд |
|---|---|---|
| Нийслэл | 1 | Хамгийн том зах, шинэ машин, хотын гэрээ, Улсын баяр наадам |
| Аймаг | 2 | Аймгийн төвийн зах, тоног төхөөрөмж, аймгийн наадам |
| Сум | 10 (аймаг бүр 5) | Сумын төвийн зах, малын эмч, сургууль, сумын наадам |
| Баг | 40 (сум бүр 4) | Тоглогчийн амьдрах нутаг |
| Бууц | 160 (баг бүр 4) | 3D орчин, улирал тус бүрийн буудал |

### 2.2. Бүсүүд: хойд хэсэг Хангай, урд хэсэг Говь

   │                    ◆ Хангай аймгийн төв                   │

   │         [Г4 Шар-Тал]          [Г5 Улаан-Толгой]           │ ← Завсрын (говь хээр)

> Сумын нэрс түр зуурын нэр. Эцсийн нэрийг [15](15_decisions_open_questions.md) Q8-аар шийднэ. Их газрын зургийн хэлбэрийг Q15-аар шийднэ.

| Бүс | Сумд | Байгаль |
|---|---|---|
| 🌲 **Хангай (цэвэр)** | Х1, Х2, Х3 | Уул, ой, гол горхи, өтгөн бэлчээр, хүйтэн өвөл |
| 🌾 **Завсрын бүс (хээр)** | Х4, Х5, Г4, Г5 | Тал хээр, толгод, нуур, дунд зэргийн бэлчээр |
| 🏜️ **Говь (цэвэр)** | Г1, Г2, Г3 | Говь, элс, хад, булаг шанд, сийрэг бэлчээр, заг |

### 2.3. Сумын бүтэц: 4 баг

Сумын газрыг 4 хувааж, баг тус бүрийг дугаараар нэрлэнэ. Сумын төв голд нь байрлана.

```
   ┌─────────────┬─────────────┐
   │   1-р баг   │   2-р баг   │
   │ (баруун хойд)│ (зүүн хойд) │
   │      🏕️×4   │      🏕️×4   │
   ├────── 🏘️ СУМЫН ТӨВ ───────┤
   │   3-р баг   │   4-р баг   │
   │ (баруун урд)│  (зүүн урд) │
   │      🏕️×4   │      🏕️×4   │
   └─────────────┴─────────────┘
```

### 2.4. Баг: 4 бууц

Баг бүрт улирал бүрийн нэг бууц, нийт 4 бууц байна. Бууцны газрын хэлбэр бүсээс хамаарна:

| Бууц | 🌲 Хангай | 🌾 Хээр | 🏜️ Говь |
|---|---|---|---|
| ☀️ Зуслан | Голын эрэг | Нуур, голын эрэг | Булаг шанд, бүрд |
| 🍂 Намаржаа | Уулын энгэр | Толгодын энгэр | Толгодын энгэр, сайр |
| ❄️ Өвөлжөө | Уулын өвөр | Толгодын өвөр | Хад, толгодын өвөр |
| 🌱 Хаваржаа | Уулын энгэр | Тал, толгодын энгэр | Тал, хотгор |

Баг дотор мөн:
- **Отрын бэлчээр** (1): гамшгийн үед бусад айлд түр олгоно (§5).
- **Саахалт айлууд** (2–4 NPC айл): өөрийн бууцуудтай, тоглогчтой зэрэгцэн нүүнэ.
- **Онцлох газар** (1–2): доорх §3.3.

## 3. Багийг сонгох, баг бүрийн ялгаа

### 3.1. Шинэ тоглоом эхлэх

```
Аймаг сонгох → Сум сонгох → Баг сонгох → Дүрээ бүтээх → Эхлэл (Зун, 1 дэх өдөр, зуслан)
```

Сонголтын дэлгэц дээр баг бүрийн үзүүлэлт харагдана:

| Үзүүлэлт | Хүрээ | Тайлбар |
|---|---|---|
| Бүс | Хангай / Хээр / Говь | Тэжээх боломжтой мал, эхлэх мал |
| Бэлчээрийн баялаг | ★–★★★★★ | Даац, тарга авах хурд |
| Ус | ★–★★★★★ | Ус зөөх хүч, ган, хар зудын эрсдэл |
| Сумын төв хүртэлх зай | Ойр / Дунд / Хол | Зах явах хугацаа |
| Чонын эрсдэл | Бага / Дунд / Өндөр | |
| Зудын эрсдэл | Бага / Дунд / Өндөр | |
| Хөрш айл | 2–4 | Хүндлэл, тусламж |
| Онцлох газар | 1–2 | §3.3 |
| **Хүндрэл** | Амар / Дунд / Хэцүү | Дээрх бүхнийг нэгтгэсэн үнэлгээ |

**Хүндрэлийн ерөнхий чиг хандлага:**
- **Завсрын бүс:** Бүх мал тэжээх боломжтой, тэнцвэртэй. Анхлан тоглогчдод зөвлөнө.
- **Хангай:** Бэлчээр, ус элбэг, гэхдээ хүйтэн өвөл, цагаан зуд.
- **Говь:** Хамгийн хэцүү (ус, ган, хар зуд), гэхдээ ноолуур, тэмээний бүтээгдэхүүн үнэтэй.

### 3.2. 3D газрын зураг үүсгэх арга: загвар + хувилбар

> 🟡 **Санал болгож буй шийдвэр D17**: батлахыг хүлээж байна ([15](15_decisions_open_questions.md) Q13)

| Арга | Давуу тал | Сул тал | Шийдвэр |
|---|---|---|---|
| Бүрэн автоматаар үүсгэх | Агуулга хязгааргүй, хямд | Нэг хэвийн, «хиймэл», бууцны чанарыг тааруулахад хэцүү | ❌ |
| Баг бүрийг гараар хийх | Чанар хамгийн өндөр | 160 бууцны газрын зураг: жижиг багт боломжгүй | ❌ |
| **Бүсийн загвар + seed-ээр хувилбар** | Чанар өндөр, ажлын хэмжээ бага | Загварыг сайн бодож хийх ёстой | ✅ |

**Ажиллах зарчим:**

1. **12 үндсэн загварыг гараар хийнэ:** 3 бүс × 4 бууцны төрөл.
   Загвар бүрт: газрын гадаргын суурь хэлбэр, гол/булаг/нуурын төрөл, гэр барих боломжтой бүс, бэлчээрийн хэсгүүд, ургамлын багц, гэрэл, тэнгэрийн тохиргоо.
2. **Баг бүр өөрийн seed-тэй.** Seed-ээр өөрчлөгдөх зүйлс:

   | Өөрчлөгдөх элемент | Жишээ |
   |---|---|
   | Газрын гадаргын жижиг хэлбэлзэл | Толгодын өндөр, хотгорын байрлал |
   | Усны хэлбэр | Голын тохой, булагны байрлал, нуурын хэмжээ |
   | Чулуу, хад | Байрлал, тоо, хэмжээ |
   | Ургамал | Нягтрал, бут, модны төгөл (Хангай), заг (Говь) |
   | Хөрш айлын гэр | Байрлал |
   | Овоо, бууцны ул мөр | Байрлал |
   | Бэлчээрийн хэсгүүд | Хуваалт, эхлэх чанар |

3. **Онцлох газрууд:** Баг бүрт гараар бэлдсэн 1–2 онцлох элемент байрлана. Ингэснээр баг бүр санагдахуйц ялгаатай болно.
4. **Тодорхой үр дүн (deterministic):** Нэг seed үргэлж ижил газар үүсгэнэ. Хадгалах файлд seed болон тоглогчийн өөрчлөлт (гэр, хашааны байрлал, бэлчээрийн чанар) л хадгалагдана.

## 5. Отор ба нутаг сэлгэх

### 5.1. Отор (түр нүүдэл)
Зуд, ган зэрэг гамшгийн үед малаа өөр баг, сумын **отрын бэлчээр** рүү түр аваачих уламжлалт арга.

| | |
|---|---|
| Хэзээ | Цаг агаарын анхааруулга ирсэн эсвэл гамшиг эхэлсэн үед |
| Хаана | Өөр багийн отрын бэлчээр; бүсийн малын дүрэм хэвээр үйлчилнэ |
| Нөхцөл | Тухайн сумын хүндлэл 30+ эсвэл отрын төлбөр 100,000–300,000₮ |
| Хугацаа | Улирлын төгсгөл хүртэл, дараа нь өөрийн багт буцна |
| Эрсдэл | Холын зам, тээврийн зардал, гэр бүлээсээ тусдаа байх |

### 5.2. Нутаг сэлгэх (байнгын нүүдэл)
Тоглогч өөр баг, сум, аймагт бүр мөсөн нүүж болно.
- Зөвхөн нүүдлийн цонхны үед.
- Шинэ бүсэд тэжээх боломжгүй малаа зарах эсвэл айлд тавих шаардлагатай.
- Хуучин сумын хүндлэл тэнд үлдэнэ. Шинэ суманд хүндлэл 20-оос эхэлнэ (алдар хэвээр, [09](09_culture_honor.md)).

## 6. Их газрын зураг дээрх аялал

### 6.1. Аяллын хугацаа (ойролцоо)

| Маршрут | Сүрэгтэй | Морь, тэмээгээр | Мотоцикл | Машин |
|---|---|---|---|---|
| Багийн бууц хооронд | 0.5–1 өдөр | 2–4 цаг | 1 цаг | 1 цаг |
| Баг → сумын төв | 1 өдөр | 2–4 цаг | 1 цаг | 30 мин |
| Сум → хөрш сум | 2 өдөр | 1 өдөр | 4 цаг | 2 цаг |
| Сум → аймгийн төв | 3–4 өдөр | 1–2 өдөр | 6 цаг | 3 цаг |
| Аймгийн төв → нийслэл | — | 3–4 өдөр | 1 өдөр | 8 цаг |

### 6.2. Цуваа ба үйл явдал
Газрын зураг дээр тоглогчийн **цуваа** нэг тэмдэгтээр (дүрс) харагдана. Аялалд санамсаргүй үйл явдал тохиолдоно:

| Үйл явдал | Хаана | Нөлөө |
|---|---|---|
| Аян замын айл | Хаана ч | Цай уух, мэдээ сонсох, хүндлэл + |
| Явуулын ченж | Зам дээр | Худалдаа |
| Чонын сүрэг | Сүрэгтэй үед, шөнө | Хамгаалах |
| Мал төөрөх | Сүрэгтэй үед | Хайх |
| Гол гатлах, үер | Хангай, хээр | Гарам олох |
| Шороон шуурга | Говь | Хурд буурах, мал төөрөх |
| Машин эвдрэх | Машинтай үед | Засвар |
| Гуйлгачин аялагч | Хаана ч | Туслах сонголт: хүндлэл + |

### 6.3. Сүрэг хараа хяналтгүй үлдэх
Тоглогч бууцаасаа явахад сүрэг, бууц нь цаана нь симуляцаар үргэлжилнэ.

| Өдөр бүр | Нөлөө |
|---|---|
| Саагдаагүй | Сааль татарна: −10% / өдөр, буцааж сэргэхэд удаан |
| Хариулаагүй | Мал бууцны ойр бэлчиж, тэр хэсгийн бэлчээрийг доройтуулна |
| Төөрөх | Өдөрт 3% |
| Чоно | Шөнийн магадлал ×2 |

**Хамгаалах арга:**

| Арга | Нөлөө |
|---|---|
| Хоточ нохой | Төөрөлт −70% |
| Банхар нохой | Чоно −80% |
| Хөршид хариулуулах | 15,000₮ / өдөр, хүндлэл 30+; хөрш сүүг нь авна |
| Эхнэр, туслах | Бүх ажлыг хийнэ |

Энэ нь эхний үед аймаг, нийслэл рүү хол аялах нь **бодит үнэтэй** болохыг илэрхийлнэ.

### 7.2. Зудын төрлүүд

| Зуд | Шалтгаан | Тоглоомд |
|---|---|---|
| **Цагаан зуд** | Зузаан цас бэлчээрийг дарна | Бэлчээрийн гарц −80%, өвсний хэрэгцээ огцом өснө |
| **Хар зуд** | Цас ороогүй, усгүй | Ус зөөх хүч ×3, малын эрүүл мэнд буурна |
| **Төмөр зуд** | Цас гэсч дахин хөлдөж мөсөн бүрхүүл үүснэ | Мал бэлчиж чадахгүй, өвс заавал хэрэгтэй |
| **Хүйтэн зуд** | Удаан үргэлжилсэн хүчтэй хүйтэн | Саравч, хашаагүй мал даарна |

- **Анхааруулга:** Намрын сүүлээр «Энэ өвөл хатуу болох төлөвтэй» гэх мэдээ ирнэ (радио, хөрш, өвөөгийн сургаал).
- **Бэлтгэл:** Өвс, нөөц тэжээл, саравч, отор.

## 8. Амьтад ба эрсдэл

| Амьтан | Бүс | Тоглоомд |
|---|---|---|
| 🐺 Чоно | Бүгд | Шөнө, хашаагүй эсвэл нохойгүй үед магадлал өндөр. Өвөл, хавар илүү идэвхтэй |
| 🦊 Үнэг | Бүгд | Хурга, ишигт эрсдэлтэй |
| 🐭 Хулгана, огдой | Бүгд | Зоорийн хүнс сүйтгэнэ (муур хамгаална) |
| 🦅 Бүргэд, тас | Хангай, Хээр | Атмосфер |
| 🐿️ Тарвага | Хангай, Хээр | Ан (ангийн нохой), атмосфер |
| 🦌 Буга | Хангай | Атмосфер |
| 🦌 Цагаан зээр | Хээр, Говь | Атмосфер |
| 🐐 Янгир, аргаль | Говь (хад) | Атмосфер |

**Чонын механик:**
- Бууц бүр **Чонын эрсдэл** (бага / дунд / өндөр)-тэй.
- Шөнө бүр магадлалаар дайрна: хашаагүй бол ×3, банхар нохойтой бол −80%.
- Чоно 1–3 хонь, ишиг авч явж болно.
- Тоглогч чоныг алахгүй, **үргээж хөөнө**. Хүчирхийллийн дүрслэлээс зайлсхийж, байгаль хамгаалах сэтгэлгээг хадгална.

## 9. Өдөр, шөнийн мөчлөг

- Нар мандах, жаргах цаг улирлаас хамаарна: зун урт өдөр, өвөл богино өдөр.
- Шөнө одтой тэнгэр, сүүн зам харагдана (Говьд хамгийн тод).
- Гэрээс гарах утаа, голомтын гэрэл нь гэр орны дулаан уур амьсгалыг бүрдүүлнэ.
