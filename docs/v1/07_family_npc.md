# 07. Гэр бүл ба NPC

## 1. Гол дүр

- Хотод сургууль төгсөөд нутагтаа ирсэн залуу ([00_vision.md](00_vision.md)).
- Нэр, гадаад төрх, дээлний өнгийг тоглогч өөрөө сонгоно.
- Эхлэлд ганц бие бөгөөд бүх ажлаа өөрөө хийнэ.

> Эмэгтэй гол дүрийн сонголт (нөхөр сонгох) нь нээлттэй асуулт ([15](15_decisions_open_questions.md)). Кодонд «эхнэр» биш, **Spouse (хань)** гэж ерөнхийлж бичнэ.

## 2. Эхнэр

### 2.1. Нээгдэх нөхцөл
| Нөхцөл | Утга |
|---|---|
| Орон байр | Гэртэй (майхан тооцогдохгүй) |
| Хүндлэл | 40+ |
| Мал | 25+ толгой |

### 2.2. Танилцаж гэрлэх замнал

```
Танилцах → Харилцаа өсгөх → Бэр гуйх → Сүй тавих → Хурим → Бэр буулгах
```

| Алхам | Тоглоомд | Шаардлага |
|---|---|---|
| **Танилцах** | Наадам, Цагаан сар, сумын төв, айлаар орох | Нөхцөл хангагдсан байх |
| **Харилцаа өсгөх (0–100)** | Яриа, бэлэг, тусламж, хамт наадамд очих | Нэр хүнд ба гарын бэлэг нөлөөлнө |
| **Бэр гуйх** | Хадаг барьж, ах дүүгээ (өвөө) зуучлагчаар дагуулан бүсгүйн гэрт очих | Харилцаа 60+ |
| **Сүй тавих** | Бүсгүйн гэрийнхэнд бэлэг: 5 толгой мал эсвэл 500,000₮ | |
| **Хурим** | Найр хийх. Зардал 800,000–2,000,000₮; цагаан идээгээ өөрөө бэлдвэл хямд | |
| **Бэр буулгах** | Бэр гэрт ирэх ёслол, голомт залгамжлах | |

### 2.3. Сонгох боломжтой бүсгүйчүүд

Эхэнд 5 бүсгүй байна. Тус бүр өөр сумаас гаралтай, өөрийн түүх, дуртай зүйлтэй.

| Нэр (ноорог) | Мэргэжлийн төрөл | Зан чанар | Дуртай бэлэг |
|---|---|---|---|
| Сарантуяа | 🥛 Сааль сүүний эзэгтэй | Халуун дотно, хөдөлмөрч | Шинэ шанага, торгон алчуур |
| Номин | 🐑 Малчин бүсгүй | Зоригтой, морь унах дуртай | Эмээл, уурга |
| Ану | 🌿 Малын эмч | Тайван, номын дуртай | Ном, эмийн ургамал |
| Солонго | 🧵 Гар урлалчин | Уран сайханч, инээдтэй | Торго, хээтэй утас |
| Энхжин | 💼 Наймаачин | Ухаалаг, хотын туршлагатай | Утас, хотын амттан |

### 2.4. Ур чадвар (1–5 түвшин)

Харилцаа, хамтдаа хийсэн ажлаар түвшин ахина.

| Төрөл | 1-р түвшин | 3-р түвшин | 5-р түвшин |
|---|---|---|---|
| 🥛 Сүүний эзэгтэй | Өдөрт 2 багц боловсруулна (тоглогчийн хүчгүй), гарц +10% | 4 багц, гарц +20%, ★★ чанар баталгаатай | 6 багц, гарц +30%, шинэ жор (хурууд, аарц) |
| 🐑 Малчин | Хонь хариулна (тоглогчийн хүч −50%) | Бэлчээрийн чанар хадгална, тарга авах +15% | Малын зарах үнэ +15%, бэлчээр сонгох зөвлөгөө |
| 🌿 Малын эмч | Өвчтэй малыг илрүүлнэ | Үржил +25%, өвчин −30% | Үржил +40%, өвчин −50%, төл амьд гарах +10% |
| 🧵 Гар урлал | Эсгий хийнэ | Дээл, гутал хийнэ (нэмэлт орлого) | Хээтэй эдлэл ×2 үнэтэй, гэрийн тав тух + |
| 💼 Наймаачин | Зах дээр үнэ +10% | Үнэ +15%, ченжтэй тохиролцоно | Үнэ +20%, хотын гэрээ эрт нээгдэнэ |

### 2.5. Харилцааны механик
- Өдөр бүр ярилцах, хамт цай уух.
- Сэтгэл ханамж: гэрийн тав тух, хоол, хамт өнгөрүүлсэн цаг.
- Сэтгэл ханамж бага бол ур чадварын нөлөө буурна. Тоглоомд салалт байхгүй, гэр бүлийн уур амьсгал зөөлөн байна.

## 3. Хүүхэд

| Нас (тоглоомын) | Чадвар |
|---|---|
| Гэрлэснээс 1 жилийн дараа | Хүүхэдтэй болох магадлал |
| 0–5 | Гэрт байна; гэрийн аз жаргал + |
| 6+ | Хурга, ишиг хариулна |
| 7+ | **Наадмын унаач** ([06_horses.md](06_horses.md)) |
| 10+ | Үнээ саах, ус зөөх |
| 16+ | Насанд хүрч, **энчий хөрөнгө** авна (төгсгөлийн үйл явдал) |

**Хүүхдийн хурдасгасан өсөлт:** Тоглоомын нэг жил = хүүхдийн 2 нас. Ингэснээр ≈ 8 тоглоомын жилд хүүхэд насанд хүрнэ. Тохируулах шаардлагатай.

**Сургууль:** Хүүхэд 6 нас хүрмэгц өвөл сумын төвийн дотуур байранд сурах сонголт гарна. Энэ нь Монгол малчин айлын бодит амьдралын хэсэг юм.

## 5. Саахалт айл ба NPC

### 5.1. Саахалт айлууд
Баг бүрт 2–4 NPC айл байна. Тэд өөрийн 4 бууцтай бөгөөд тоглогчтой зэрэгцэн нүүнэ. Иймд нэг багийн айлууд жилийн турш хөрш хэвээр үлдэнэ. Их газрын зураг дээр бусад баг, сумын айлуудад ч зочилж болно.

| Үйлчилгээ | Нөхцөл |
|---|---|
| Сүү, бүтээгдэхүүн худалдаж авах | Хязгаартай, ×0.7 үнэтэй |
| Тарагны хөрөнгө өгөх | Хүндлэл 20+ |
| Хээлтүүлгийн мал хөлслүүлэх | |
| Мал тавих (маллуулах) | Хүндлэл 30+ |
| Мөнгө зээлэх | Хүндлэл 40+ |
| Хот айл болж хамт нүүх | Хүндлэл 50+ |
| Гэр барихад туслах | Хүндлэл 30+ (үнэгүй) |
| Хол аялах үед сүргийг хариулж саах | Хүндлэл 30+, 15,000₮ / өдөр, сүүг нь авна ([11](11_world_weather.md) §6.3) |
| Говийн тоглогчийн морийг маллах (завсрын сумын айл) | Хүндлэл 40+, улиралд 50,000₮ / морь |

### 5.2. Гол NPC-үүд

| NPC | Үүрэг |
|---|---|
| **Өвөө** | Сургалт, сургаал, түүхийн гол дүр |
| **Эмээ** | Цагаан идээний жор, ёс заншлын зөвлөгөө |
| **Ченж** | Явуулын худалдаачин, 7 хоног тутам ирнэ |
| **Сумын малын эмч** | Вакцин, эмчилгээ |
| **Сумын дэлгүүрийн худалдагч** | Хүнс, хэрэгсэл |
| **Засаг дарга** | Цол олгох, бэлчээрийн эрх, наадам зохион байгуулна |
| **Хурдан морины уяач** | Морь сургах зөвлөгөө, өрсөлдөгч |
| **Бөх** | Наадмын бөхийн мини тоглоомын өрсөлдөгч |

### 5.3. Харилцааны систем
- NPC бүр **Харилцаа (0–100)** үзүүлэлттэй.
- Ерөнхий **Хүндлэл** нь бүх NPC-ийн эхлэх харилцааг тодорхойлно ([09_culture_honor.md](09_culture_honor.md)).
- Бэлэг: NPC бүр дуртай, дургүй зүйлтэй.
- Төрсөн өдөр, баяр ёслолоор урих.
