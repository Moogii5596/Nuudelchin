# 16. Нэр томьёоны толь

Кодын нэршилд англи `snake_case` (өгөгдөл) болон `PascalCase` (класс) ашиглана. Монгол нэрийг орчуулгын файлд (`mn.json`) хадгална.

## 1. Нүүдэл ба бууц

| Монгол | Код ID | Тайлбар |
|---|---|---|
| Нүүдэл | `migration` | Улирал солигдоход бууц солих |
| Бууц | `camp` | Айлын буудаг газар |
| Зуслан | `camp_summer` (`zuslan`) | Зуны бууц, голын эрэг |
| Намаржаа | `camp_autumn` (`namarjaa`) | Намрын бууц, уулын энгэр |
| Өвөлжөө | `camp_winter` (`uvuljuu`) | Өвлийн бууц, уулын өвөр |
| Хаваржаа | `camp_spring` (`khavarjaa`) | Хаврын бууц, уулын энгэр |
| Нүүдлийн цонх | `migration_window` | Цагтаа нүүх хугацаа |
| Ачааны нэгж (АН) | `load_unit` | Нүүдлийн ачааны хэмжүүр |
| Хот айл | `khot_ail` | Хамт нутагладаг хэдэн айл |
| Саахалт айл | `neighbor` | Ойрын хөрш айл |
