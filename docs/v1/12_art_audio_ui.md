# 12. Уран сайхан, дуу хөгжим, интерфейс

## 1. Уран сайхны чиглэл

### 1.1. Хэв маяг
- **Шийдэлтэй low-poly (stylized low-poly):** Цэвэр хэлбэр, өнгөний том толбо, нарийн бүтэц (texture) бага.
- **Тэнгэр гол баатар:** Өргөн тэнгэр, үүл, гэрлийн өөрчлөлт, нар жаргах үеийн өнгө.
- Өдрийн цаг, улирал бүр өөрийн **өнгөний палитртай**.

| Улирал | Гол өнгө |
|---|---|
| Хавар | Цайвар ногоон, шаргал хүрэн, хүйтэн цэнхэр тэнгэр |
| Зун | Тод ногоон, хөх тэнгэр, цагаан үүл |
| Намар | Алтан шар, улбар шар, гүн цэнхэр |
| Өвөл | Цагаан, цэнхэр сүүдэр, шар гэрэл (гэрийн цонх) |

### 1.2. Лавлах материал
- Монгол тал нутгийн гэрэл зураг (өөрсдөө авах, эсвэл лицензтэй).
- Угсаатны зүйн музейн гэр, хувцас, багаж хэрэгсэл.
- Монгол зураг (уламжлалт урлаг)-ийн өнгө, найруулга.

### 1.4. Олон малыг дүрслэх
1000 мал нэгэн зэрэг харагдах үед GPU instancing, LOD ашиглана ([13_technical.md](13_technical.md) §4). Алсаас харахад сүрэг цагаан, хүрэн толбо мэт харагдана. Энэ нь бодит Монгол тал нутгийн дүр төрх юм.

## 2. Дуу ба хөгжим

### 2.1. Хөгжим
| Хэрэгсэл, хэв маяг | Хэзээ |
|---|---|
| Морин хуур | Үндсэн сэдэв, өдрийн тайван үе |
| Уртын дуу | Өглөө, нүүдлийн аялал, онцгой мөчүүд |
| Хөөмий | Шөнө, уул, нууцлаг үе |
| Ятга, лимбэ | Гэрийн доторх, гэр бүлийн мөчүүд |
| Хурдан хэмнэлтэй ардын ая | Наадам, уралдаан |

> Бүх хөгжмийг шинээр зохиож бичүүлнэ. Ардын аялгууг ашиглахдаа хэрэглэх эрхийг тодруулна.

### 2.2. Орчны дуу
- Салхи (улирал бүр өөр), голын урсгал, шувуу, царцаа.
- Малын дуу: хонь майлах, үнээ мөөрөх, морь янцгаах, тэмээ буйлах.
- Гэрийн дотор: галын шажигнах дуу, цай самрах, тооноор орох салхи.

### 2.3. Дуу хоолой
- NPC-ийн яриа текстээр, богино дуу хоолойн хэллэгтэй («За», «Сайн байна уу», «Мэнд үү»).
- Бүрэн дуу хоолой нь ирээдүйн шийдвэр.

## 3. Интерфейс (UI/UX)

### 3.1. Зарчим
- **Бага HUD:** Ертөнц өөрөө мэдээлэл өгнө (өвсний өнгө, малын төрх).
- **Монгол хээ угалз:** Цонхны хүрээ, товчлуурт ашиглана.
- **Үсэг:** Кирилл үсэг үндсэн. Монгол бичгийг чимэглэл, гарчиг, кодексод ашиглана.

### 3.4. Удирдлага
- **PC:** WASD + хулгана. Сүрэгт тушаал өгөх радиаль цэс.
- **Gamepad:** Анхнаасаа дэмжинэ.

### 3.5. Хүртээмж (Accessibility)
- Мини тоглоом бүрийг алгасах эсвэл автоматжуулах сонголт.
- Үсгийн хэмжээ, өнгөний ялгааг тохируулах.
- Цаг хурдыг тохируулах (8–20 мин / өдөр).
