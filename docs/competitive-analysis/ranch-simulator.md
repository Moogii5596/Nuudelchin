# Өрсөлдөгчийн шинжилгээ — Ranch Simulator: Build, Hunt, Farm

> **Төлөв:** 📚 Судалгаа (2026-11-15). Санаа зээлэх, алдаанаас сэрэмжлэх лавлагаа — дүрэм биш. Шийдвэр гаргавал `mvp-spec.md` §0 / §13-д оруулна.
> **Яагаад чухал вэ:** Мал маллага + хашаа барих + чоноос хамгаалах + ан + бүтээгдэхүүн боловсруулах — **механикаар манайхтай ойр**, арилжааны хувьд том (3 сая+ тоглогч), гэхдээ үнэлгээ нь «Ихэвчлэн эерэг» — **юу буруу хийснийг** судлахад тохиромжтой.
> **Дугаарлалт:** RS1–RS12.

## 2. Гол давталт

1. Өвөөгийн **эвдэрсэн ранчийг** өвлөнө (Stardew, RVS 2-той ижил «өвлөгч» оршил).
2. Байшин засах, нурааж дахин барих; амбаар, хашаа, хэвтэр барих.
3. Мал (тахиа, үхэр, гахай; дараа нь морь, Highland үхэр DLC) авч тэжээх, услах.
4. Ранчийг **өлсгөлөн чоноос** хамгаалах.
5. Ан агнах, тариа тарих, хиам, бяслаг хийх; машинаар явж бүтээгдэхүүнээ зарах.
6. Олсон мөнгөөр барилга, тоног нэмэх; морь сургаж зарах.

## 3. ✅ Сайшаасан зүйлс

1. **Ранч барьж өргөтгөх** — хөдөө рүү таатай зугтах, үзэсгэлэнтэй дүрслэл.
2. **Co-op** — найзуудтайгаа ранч удирдах, хамтдаа хөгжилтэй мөчүүд — хамгийн их сайшаасан онцлог.
3. **Хошигнол** — физикийн алдаа, эвгүй байдлаас үүссэн инээдтэй мөчүүд (100% эерэг дурдлага).
4. **Малтай сэтгэлээр холбогдох** — «хэт таргалсан гахайтайгаа сэтгэл холбогдсон тул устгах хэрэгтэй болсон» (Herdling-ийн холбоотой ижил).
5. **Нээлттэй ертөнц, худалдах давталт** — ан, бүтээгдэхүүн зарах аялал ажилладаг.

## 5. Манай тоглоомд хамаарах сургамж

Ranch Simulator бол «**сайн санаа + сул хэрэгжилт** = олон хэрэглэгч, гэхдээ дунд зэргийн үнэлгээ»-ний жишээ. Сэдэв (ранч, мал, чоно, co-op) хүмүүсийг татсан ч grind, алдаа, хоосон байдал хадгалж чадаагүй.

### 5.1 Авах санаа 🟢

| # | Санаа | Манайд хаана | Тайлбар |
|---|---|---|---|
| RS1 | **«Өвлөгч» оршил** | эхлэл | Stardew (SV6), RVS 2 (RV4), Ranch Simulator — **3 амжилттай тоглоом** ижил оршилтой. Монгол хувилбар: «өвөө эмээгийнхээ нутаг, хэдэн малыг өвлөж хотоос ирсэн залуу». Манай эхлэлийн 10 хонь, 2 үнээ, 1 морь энэ түүхэнд яг тохирно |
| RS2 | **Барилга сэргээх/өргөтгөх бахархал** | бууц, хот | Майхан → гэр → хашаа → саравч → худаг → өвөлжөөний байшин. Бууц бүрийг аажмаар тохижуулах (MD7-той нийлнэ) |
| RS3 | **Бүтээгдэхүүн боловсруулах** | `night-transport.md`, V1 | Хиам, бяслаг → манайд ааруул, өрөм, шар тос, борц (RV2-той нийлнэ — **2 дахь** баталгаа) |
| RS4 | **Мал сургаж зарах** | V1 | Морь сургаж зарах → манайд **хурдан морь** уяж Наадамд уралдуулах эсвэл зарах. Уяачийн мэргэжил (`family-generations.md` §5)-тэй холбогдоно |
| RS5 | **Хамтын тоглолт (co-op)** | V2+ (MVP-д үгүй) | Хамгийн их сайшаасан онцлог. Гэхдээ манай хамрах хүрээг хэт өргөсгөнө (Nomad Y2). **V2+-д** найз «саахалт айл» болж ирэх хэлбэр — `architecture.md`-ийн sim/render салангид бүтэц үүнд бэлэн байж магадгүй |
| RS6 | **Малтай холбоо** | H4, H5 | Нэр өгөх, хайрлах — гурав дахь тоглоом ижил дүгнэлт (Herdling, Khiimori, Ranch) |

### 5.3 Ranch Simulator-аас ялгарах

- **Нүүдэл** — ранч суурин; манайд 4 бууц, улирлын нүүдэл.
- **Бэлчээр экологи** — Ranch-д тэжээл хийнэ; манайд мал өөрөө бэлчиж, тарга, даац, доройтол.
- **Физикгүй, тогтвортой** (RS9).
- **Хөнгөн** — вэб/PWA vs. UE4-ийн хүнд оновчлол.
- **Соёлын гүн** — Америк ранчийн ерөнхий дүр төрх биш, тодорхой монгол ахуй.

## 6. Нээлттэй асуулт (🙋 → `mvp-spec.md` §13)

1. RS1 — «өвөө эмээгийн нутгийг өвлөсөн» оршил уу, «хотоос буцаж ирсэн» (RV4) уу, хоёуланг нийлүүлэх үү?
2. **RS8 — дуу чимээний төлөвлөгөө (амьтан, байгаль, хөгжим) MVP-д хэр тусгагдсан бэ?** `visuals-plan.md`-д шалгах. *(чухал)*
3. RS5 — co-op-ыг V2+-ийн алсын хараанд оруулах уу?
4. RS4 — хурдан морь уях, Наадамд уралдуулах V1-д уу?
