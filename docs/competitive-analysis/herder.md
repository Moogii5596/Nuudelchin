# Өрсөлдөгчийн шинжилгээ — Herder

> **Төлөв:** 📚 Судалгаа (2026-11-15). Санаа зээлэх, алдаанаас сэрэмжлэх лавлагаа — дүрэм биш. Шийдвэр гаргавал `mvp-spec.md` §0 / §13-д оруулна.
> **Анхаар:** Маш жижиг тоглоом (Steam-д ~13 сэтгэгдэл), шүүмжлэгчийн үнэлгээ байхгүй. Дүгнэлт нь ихэвчлэн **дизайны бүтэц** дээр тулгуурласан, тоглогчийн санал цөөн.
> Өмнөх: `khiimori.md`, `nomad-steppeborn-saga.md`, `herdling.md`.

## 2. Гол давталт

1. Эхлээд жижиг сүрэг авах хэмжээний мөнгөтэй эхэлнэ.
2. **Шинэ бэлчээрт ирээд** хаалгаа нээж малаа гаргахаас өмнө хамгаалалтын хэрэгслээ байрлуулна (tower defense бэлтгэл).
3. Хонь, ямаа өвс, цэцэг идэж бэлчинэ — **бэлчээр дуусахад** дараагийн бэлчээр рүү нүүнэ.
4. Зэрлэг амьтнаас хамгаална (зэвсэг, хэрэгсэл, нохой).
5. Ноос, сүү, малаа **дайран өнгөрөх жингийн цуваа (caravan)**-нд зарж, шинэ хэрэгсэл, мал авна.
6. Хүссэн үедээ **мөнгөө аваад дуусгах** (cash out) эсвэл сүрэг махчин, өлсгөлөн, өвчинд сүйртэл үргэлжлүүлнэ. Эцсийн мөнгө = оноо, шинэ нугад дахин эхэлнэ.

## 3. Системүүд

- **Бэлчээр шавхагдах → нүүх:** нэг газрын өвс дуустал бэлчээд дараагийнх руу.
- **Нүүх тусам эрсдэл өснө:** бэлчээр бүр зэрлэг газар руу гүнзгий орох тусам махчин ихсэж, жингийн цуваа цөөрнө.
- **Улирал механиктай холбоотой:** намар баавгай гарна, өвөл сүрэгт өвс хэрэгтэй, хавар хурга төрнө.
- **Үржүүлэг, саалт, хяргалт:** сүргээ эрүүл, сэтгэл хангалуун байлгавал үржиж, саагдаж, хяргагдана. Өвчин (тахал) бий.
- **Мал маллах нохой** — найрсаг туслах.
- **Хэрэгсэл:** хамгаалалтын барилга, зэвсэг, тэр дундаа мина — тоглогчид бүх мал нь тахал, чоно, **мина**-д үхсэн гэж тоглоомоор бичсэн.
- **Тайван (casual) горим:** сүрэг тайван бэлчинэ, тоглогч зүгээр суугаад малаа бэлчээрт гаргах амар амгаланг таашаана.
- **Уур амьсгал:** хурц, тайвшруулах өнгөний палитр, бэлчээрт хонины дуу, нугын салхи.

## 4. ✅ Сайшаасан зүйлс

1. **Тариалан × tower defense хослол** — хоёр жанрыг гайхмаар сайн хольсон, шинэлэг.
2. **Өнгө, орчин** — өвөрмөц, нүдэнд таатай, тайвшруулах.
3. **Хонь илж болдог** — богино ч гэсэн сэтгэгдэлд дурдагдсан.
4. **Үнэ/агуулгын харьцаа** — «$5-ын үнэ цэнэтэй».
5. **Тэнцвэр** — сайн тэнцвэржүүлсэн гэж үнэлсэн.

## 5. ❌ Шүүмжилсэн зүйлс

1. **Хонь тэнэг — аюул руу гүйдэг.** «Хонь аюулаас холдох биш, яг тийшээ гүйдэг» — 5 цаг тоглосон тоглогч.
2. **Удирдлага хачин** — «жижиг студи хийсэн нь илт».
3. **Тайван горимд ч амжилт (achievement) маш хэцүү**, буудлага сул.
4. **Grind (давтагдсан хөдөлмөр)** — сэтгэгдлүүдэд сөрөг утгаар 3 удаа дурдагдсан.

## 6. Манай тоглоомд хамаарах сургамж

Herder бидэнтэй **механикийн хувьд хамгийн ойр**: бэлчээр шавхагдах → нүүх, улирал → өвс/төл, нохой, үржүүлэг/саалт/хяргалт, худалдаачинд зарах. Ялгаа нь: Herder бол **оноо хөөсөн богино тоглолт (roguelite)**, бид **дуусахгүй, тайван симулятор**.

### 6.2 Зайлсхийх зүйл 🔴

| # | Эрсдэл | Манайд юу хийх |

| R10 | **Тайван горимд ч хэцүү амжилт** | Хэрэв Steam achievement нэмбэл тайван горимд ч хүрч болох байх; эсвэл горим бүрт тусдаа |

| R12 | **Тулаан, мина** | Малчны тоглоомд зэвсэг, мина гэх мэт хэрэгсэл соёлд үл нийцнэ. Манайх: нохой, хашаа, «Хуу-хай!», хотлох |

### 6.3 Herder-ээс ялгарах

- **Тулаангүй хамгаалалт** — Herder бууддаг, бид бэлтгэл, байршил, нохой, цаг хугацаагаар хамгаалдаг.
- **Бодит бэлчээрийн экологи** — Herder-д өвс зүгээр «дуусдаг», манайд тарга, даац, доройтол, сэргэлт.
- **Тасралтгүй амьдрал** — оноо биш, гэр орон, гэр бүл, үе удам (`family-generations.md`).
- **Олон зүйлийн мал** (5 хошуу) — Herder зөвхөн хонь, ямаа.
