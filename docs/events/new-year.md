# Event — Шинэ жил

> Ноорог (T-22). Код бичихээс өмнөх тодорхойлолт ([[decisions]] 2026-11-17 D). Тоон утга `data/*.json`-д ОРООГҮЙ — санал хэлбэрээр; 🙋 = тэнцвэрээр тааруулна, ⚠ = баталгаажуулах. Эх сурвалж: [[story]] §3, §4.1–4.2, §6.6; [[story-loop]] §3–4; [[winter-prep]] §5, §7; `data/wolves.json`, `seasons.json`, `npcs.json`. Дараагийн event: [[tsagaan-sar]].

## 1. Тойм

- **Хэзээ:** 1-р жил өдөр 12 (өвөл 5-р өдөр); 2-р жил өдөр 62. Нөгөө тал: өдөр 10–20 бүхэлдээ нэг «өвлийн цонх» — чоно (10), Шинэ жил (12), ан (13–19), өвчин (15–17), дурсамж (18), тооллого (20).
- **Зорилго:** өвлийн хамгийн хүнд, мөнгө хомс үеийг (өдөр 15–23) **харилцаагаар** давуулах. Тоглогч нэг сонголт хийнэ: хамт гарах уу, малдаа үлдэх үү. Аль нь ч буруу биш.
- **Тайван дүрэм:** шийтгэл, таймер, «амжаагүй» мэдэгдэл, game over байхгүй. Өвчин нь хэн нэгний хохирол биш, **тусалах боломж**.
- **Гурван урсгал** (бие даасан, нэг өдрийн цонхонд давхцаж болно):

| # | Урсгал | Өдөр | Гол сонголт | Ургуулдаг механик |
|---|---|---|---|---|
| A | Шинэ жилийн оройн зоог | 12 | Сумын төв / хамаатны гэр / малдаа үлдэх | `relations` + ; бэлэг |
| B | Чонын ан | 13–19 | Хамтрах / ганцаараа / хийхгүй | `wolves.hunt` |
| C | Өвчлөх (эмээ, хамаатан) | 15–17 | Эргэж очих / утсаар асуух | `relations` +; шийтгэлгүй |
| D | Хүйтрэлт (цаг агаар) | санамсаргүй 15%/өвөл | Малаа хашаанд / гадаа | [[winter-prep]] §5 `coldMult` |

## 2. Урсгал A — Шинэ жилийн оройн зоог (өдөр 12)

**Өглөө 08:00** утас: эмээ залгана — «Орой сумын төвд ирж болох уу? Хамаатнууд цугларна». Мөн хөрш Мөнхбат (`npcs.json` herder): «Маргааш авд хамт гарах уу?» (урсгал B-ийг нээнэ).

| Сонголт | Нөхцөл | Үр дагавар |
|---|---|---|
| **Сумын төв / хамаатны гэрт очих** (≈ 2 цаг зам) | Малаа өглөө тэжээсэн, хотлуулсан | Хамаатан 1–2 дулаан +10 (`warmthGain.newYearVisit`); нэг орой тоглогч «гэр»-ээс гарна (цаг 18–22); бэлэг өгвөл +5 нэмэлт |
| **Малдаа үлдэх** | — | Дулаан өөрчлөгдөхгүй (шийтгэлгүй); эмээ утсаар: «Малаа харсан нь зөв, хүү минь»; бага зэрэг тарга + (илүү тэжээх цаг) |
| **Хөршийг ууж ирүүлэх** (2-р жилд л) | Өвөө, эмээ танайд | Өвөө, эмээ, хөрш цугларч оройн зоог гэртээ; дулаан +8 хөрш |

- **Бэлэг:** хэрэглэгч өөрийн нөөцөөс (сүү, тараг, мах, цагаан идээ) сонгож өгнө. Мөнгөөр худалдаж авах шаардлагагүй (мөнгө хомс үе). 1 нэгж бэлэг ≈ дулаан +3, хамгийн ихдээ +9/хүн.
- **Үзэгдэл:** гэр дотор гэрэл, ширээнд бууз, сүүтэй цай, шөл. Гадаа оддын хөдөлгөөн; цэвэр үүртэй бол тэнгэрт од. Хөгжим байхгүй (A6 MVP дуугүй, [[decisions]]) — зөвхөн гэр доторх орчны дуу.
- **2-р жил (өдөр 62):** гурвуулаа (тоглогч, өвөө, эмээ) гэртээ. Сонголтгүй, 1 дэлгэц: өвөө «Манай үеийн Шинэ жил» гэж 1 түүх (§6) ярина. Дулаан өөрчлөгдөхгүй; «Малчны тэмдэглэл»-д хуудас нэмэгдэнэ.

## 3. Урсгал B — Чонын ан (өдөр 13–19)

Өдөр 10-ын анхны чоно ([[story]] §4.1) → өвөөгийн зөвлөгөө: «Мөрийг нь дага, үүрийг нь мэдэж ав». Өдөр 13–19 ан хийх боломж нээгдэнэ; 2-р жилд 63–69. Ан нь «хөрш, садантай хамтарвал илүү» гэсэн сонголт ([[story]] §6.6).

### 3.1 Дараалал

1. **Мөр илрүүлэх.** Тоглогч `wolves.json`-ийн үүрийн байршлыг (`denDistance` 120–145 м) бууцнаас хайна. Үүр нэг удаа «мэдэгдсэн» болно (газрын зураг дээр тэмдэг).
2. **Хамтрагч сонгох** (утасны «Хөрш» хуудас):
   - **Хамтрах:** Мөнхбат (хөрш 1) + (дулаан ≥ 40 бол) хамаатан. 1–3 хүн.
   - **Ганцаараа:** тоглогч + нохой.
   - **Хийхгүй:** өөрийн малаа хамгаална; ан хаагдахгүй (7 өдрийн цонхонд дахин боломж).
3. **Үүрт очих** (шөнө биш, цаг 9–16; цаг агаар «хүйтрэлт» биш). Ан = хоёр шат: үүрийг тойрох (≤ 20 мин) → үүрийг авах (чоно гөлөг гаргасан эсэхээс үл хамаарна).
4. **Үр дүн** (амжилтын магадлал; ⚠ `wolves.hunt` шинэ):

| Хэлбэр | Амжилт | Өвөл амжилтын эрсдэл | Үр дагавар |
|---|---|---|---|
| Ганцаараа | `soloChance` ≈ 0.35 🙋 | Чоно зугтаж, үүр өөр газар шилжинэ (бүс чонгүй болохгүй) | Бүс 1–2 жил чонгүй (амжилтад), өвөө загнахгүй |
| Хөрштэй | `groupChance` ≈ 0.7 🙋 | Бага | Бүс чонгүй + хөршийн дулаан +10 |
| Бүлгээр (3 хүн) | `groupChance` + 0.1 | Бага | Дээрхтэй адил + нэмэлт дулаан +5 |

- **«Чонгүй бүс»:** `clearDays` ≈ [50, 100] 🙋 (1–2 жил); амжилттай ан хийсэн үүр бүрийн орчим. Чоно тэр бүсэд дахин үүр засахгүй; харин чоно ирж болох **бусад** үүрэнд хамаарахгүй.
- **Ангийн дараа:** өвөө «Одоо чинь хонио хэдэн шөнө тайван нойртой болно». Малчны тэмдэглэлд «Миний анхны ан» мөр.
- **Нөхцөл:** ан хийх тоглогч өөрийн малаа үлдээх үед нохой / туслахтай байх (чоно дайралт шөнө л болно, `protectRadius` өдөрт хамгаалдаг) — шинэ механик байхгүй.
- **Тайван дүрэм:** ан амжилтгүй болбол мэдэгдэл «Чоно зугтлаа» гэж; торгууль, малын хорогдол нэмэгдэхгүй.

## 4. Урсгал C — Өвчлөх (өдөр 15–17, 2-р жилд 65–67)

- **Хэн:** 1-р жил — эмээ (Хульжийн курсийн үеэр ханиад хүрнэ; [[story]] §4.1 өдөр 15–17), эсвэл дулаан ≥ 50 хамаатан. 2-р жил — өвөө ханиад хүрч гэртээ хэвтэнэ.
- **Дохио:** оройн утас: эмээ ханиасан хоолойгоор «Бага зэрэг ханиад хүрлээ. Эмнэлэгт хэвтэж байна» (1-р жил, ресортын эмч 1 хоног хүргэж ирнэ).
- **Сонголт (шийтгэлгүй):**

| Сонголт | Үр дагавар |
|---|---|
| **Эргэж очих** (сүү, шөл, цагаан идээ авч, сумын төв) | Нөөцөөс 1 нэгж бэлэг → дулаан +10 (`warmthGain.sickVisit`); 1 өдөр замд; эмээ: «Чи хүрээд ирэв үү!» |
| **Утсаар асуух** | Дулаан +3; эмээ: «Битгий санаа зов, хүү минь» |
| **Юу ч хийхгүй** | Өөрчлөлтгүй; шийтгэл, «дулаан –» байхгүй. Эмээ зөвхөн нэг сул үг: «Малаа харж байгаа биз» |

- **Өвөөгийн ханиад (2-р жил):** өвөө «чоно, мал»-ын зөвлөгөөгөө тэр хоногт өгөхгүй (гэртээ хэвтэж); тоглогч шөл, цагаан идээ барьж өгч болно → дулаан +10, мөн өвөөгийн дурсамж нэг (§6) нээгдэнэ.
- **Малын өвчин** энэ event-д ОРОХГҮЙ (вакцин, Доржпалам — өөр event).

## 5. Урсгал D — Хүйтрэлт

[[winter-prep]] §5-ийн санамсаргүй төлөв ашиглана (`weather.episodes.coldSnap`, өвөл бүр 15%). Энэ event-д зөвхөн **түүх, мэдэгдэл** нэмнэ:

- **3 хоногийн мэдээ** (утас): «Ирэх 3 хоног −38°-д хүрнэ».
- **Хүйтрэлтийн орой (өдөр 18 болох үед):** өвөө 1967 оны өвлийн газар хөдлөлтийн дурсамжийг ярина (Малчны тэмдэглэл, [[story]] §4.1). Хүйтрэлт байхгүй бол 18-р өдөр энэ нь «хэвийн хүйтэн орой» хувилбараар ярина — дурсамж үргэлж гарна.
- **Сонголт:** малаа хашаанд (түлш, өвс илүү) / гадаа гаргах (тарга хорогдоно) — [[winter-prep]] §4 хэвээр.

## 6. Өдөр 20 — Өвлийн тооллого

- Нэгтгэсэн «Өвлийн тооллого» (утас → Мал): хорогдол N% (шийтгэлгүй, мэдэгдэх).
- Ганбаатар (худалдаачин): «Хавар мах үнэд орно» (`economy.priceSeason`), сонголт: үлдсэн мах зарах / хадгалах.
- Харилцааны хураангуй: Шинэ жилээр шинээр дулаарсан хүмүүсийн нэг мөр.

## 10. Command, sim, UI

- **Sim:** `sim/systems/events.ts` (шинэ) — event хуваарь (өдрөөр), нөхцөл, үр дагавар; `sim/systems/hunt.ts` (шинэ) — ан; Three.js-гүй ([[architecture]]).
- **Command:** `AcceptEventChoice {eventId, choice}`, `StartHunt {denId, partners[]}`, `GiveGift {npcId, items[]}`, `VisitNpc {npcId}`. Тоглогчийн бүх үйлдэл Command-оор.
- **UI:** утасны «Хөрш» хуудас (ан санал), зоогийн сонголтын цонх (нэг dialog), дэвтэр. Шинэ цонх бүхий нийтлэг dialog-ийг дахин ашиглана ([[AGENTS]] §5).
- **Render:** оройн гэр (гэрэлтсэн), од, ангийн үед үүр тэмдэг. Draw call нэмэгдэхгүй (instanced).

## 11. Шалгуур (тест)

1. Өдөр 12 → зоогийн санал; 3 сонголт бүр үр дагавартай, шийтгэлгүй.
2. Бэлэг ≤ 3 нэгж/хүн; `eventCap` ≤ 25 хэтрэхгүй.
3. Ан: `solo` / `group` магадлал seed-ээр тодорхой (12 seed-ийн тархалт); амжилтад бүс `clearDays` хугацаанд чонгүй.
4. Ан амжилтгүй бол малын хорогдол, дулаан буурахгүй.
5. Өдөр 18: хүйтрэлт байсан эсэхээс үл хамааран дурсамж гарна.
6. 2-р жил: өдөр 62 хүн цөөхөн (3) хувилбар; өвөөгийн ханиад 65–67-д зөвлөгөө түр нуугдана.
7. Хуучин save-ийг шилжүүлэхгүй ([[decisions]] E).
