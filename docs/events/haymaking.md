# Event — Хадлан

> Ноорог. Тоо бүгд **санал** (🙋). Суурь: [[winter-prep]] §3f, [[story]] §4 (46–), [[story-loop]] §2, §4.1 (даалгавар 25), [[decisions]] §13-8 (анхдагч: боодол өвс, хадлан сонголтоор). Давхцал: [[airag]] (41–49).

## 1. Тойм

- **Зорилго:** сонголтын event. Өвс худалдаж авахын оронд өөрийн талбайг хадаж, боодол болгож өвөлжөөнд хүргэнэ. Хөдөлмөрийн өртөг ≈ 6,250₮/боодол (хөлсний туслах 25,000₮ ÷ 4), дэлгүүр 14,000₮.
- **Эхний жил:** хөнгөн хувилбар — **3 га** (30 боодол ≈ хэрэгцээний 29%), өвөөгийн өвөлжөөний хашсан талбай. 2-р жил (намрын эхнээс): бүрэн event.
- **Хэмжээ:** хэвийн жилийн хэрэгцээ ≈ 103 боодол, найдвартай 145 ([[winter-prep]] §3). Үлдсэнийг дэлгүүр, худалдаачнаас.
- **Шийтгэл байхгүй:** хадаагүй бол өвс худалдаж авна (даалгавар 25 биелэхгүй, бусад зүйл өөрчлөгдөхгүй).

## 2. Ажлын шат

| Шат | Үйлдэл | Хугацаа |
|---|---|---|
| Хадах | Хадуураар (4 боодол/хүн-өдөр = 3 цаг 🙋) | 46–48 |
| Хатаах | Хуурай 2 өдөр, өдөр 0.5 цаг эргүүлнэ | +2 өдөр |
| Боодол | Цуглуулж боодол болгоно (ажлын хуваарьт багтана) | 48–50 |
| Хүргэлт | Боодол бэлэн болмогц **маргааш өглөө** өвөлжөөнд (мэдэгдэл) | автомат |

- **Бороо, цас:** хуурай 2 өдөр дутвал хатаах нь түр зогсоно (ажил үргэлжилнэ, цаг зарцуулахгүй). Дараа жил: техник 12 боодол/хүн-өдөр.
- **Хүчин чадал:** 3 га × 10 боодол/га = 30 боодол = 7.5 хүн-өдөр (22.5 цаг).

## 3. Хүн ажил ба өртөг

| Хүн | Боодол/өдөр | Өртөг |
|---|---|---|
| Тоглогч (2 цаг) | 2.7 | 0 |
| Хөлсний туслах | 4 | 25,000₮/өдөр |
| Хөрш, хамаатан (хамтын ажил) | 4 | 0, хариуд хөрш хяргалт, хадланд очно (дулаан +) |

Эхний жил 30 боодол: тоглогч 2 цаг × 5 өдөр ≈ 13 боодол + 1 туслах × 5 өдөр ≈ 17 боодол (125,000₮ ≈ 4,200₮/боодол) эсвэл хөрш.

## 4. Давхцлын шийдэл ([[airag]]-тай)

Өдөр 46–49-д гол + байнгын ажил ≤ **8 цаг**. Хадлангийн тоглогчийн цаг = 8 − (бусад ажил):

| Бүрэлдэхүүн (цаг) | 46–49 |
|---|---|
| Байнгын (мал тоолох, утас, хотлуулах) | 2.0 |
| Сүү, цагаан идээ | 1.0 |
| Айраг (саах 3 удаа + тогтмол 2.5) | 4.0 |
| **Дэд нийт** | **7.0** |
| Хөнгөлөлт: хүүхэд унага барина | −0.5 → 6.5 |
| Хөнгөлөлт: туслах саах тойрог авна | −1.5 → 5.0 |
| **Хадланд боломжит (тоглогч)** | 1.0 / 1.5 / **3.0** |

**Санал болгож буй зам (A):**

1. **Дараалал:** 41–45 айраг; 46 хадлан нээгдэнэ.
2. **Хөнгөлөлт:** 46–49-д хөлсний туслах 1 хүн утсаар дуудна (хадах + саах хуваарилалт); хамаатны хүүхэд (дулаан ≥ 40) унага барина.
3. **Хугацаа:** хадлан 46–50 (5 өдөр); дуусаагүй хэсэг ажил дараа жил үргэлжилнэ (хураагаагүй өвс 10% буурна 🙋).
4. **Эх сурвалж хоёр:** хэрэв тоглогч туслах хөлсөлж чадахгүй бол хөрштэй хамтарч (дулаан ≥ 40) хадна.

**Сонголт B (хөнгөн):** хадлангийн цонхыг 46–49 → 50–52 (2-р жилд намрын 5+ өдөр) болгох. **Зөвлөмж:** A — зарчим 4 («Гар ажил → хөнгөлөлт») нийцэнэ; B хэтэрсэн ачаалалтай тоглогчид «орхих» хувилбар болгон үлдээнэ.

**Хэт ачаалал:** хөнгөлөлтгүй бол нийт 46–49-д 8-аас хэтэрнэ (≈ 10 цаг) → тоглогч өөрөө аль нэгийг нь орхино (§1).

## 6. Шалгуур

1. 46–49-д байнгын + гол ажил ≤ 8 цаг (хөнгөлөлттэй), тусламжгүй бол 10 цаг (мэдэгдэх).
2. Эхний жил 30 боодол (±10%); өртөг ≤ 6,250₮/боодол.
3. Даалгавар 25: нэг талбай хадахад биелнэ.
4. Хүргэлт маргааш өглөө; мэдэгдэл.
