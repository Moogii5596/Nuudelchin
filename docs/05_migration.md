# 05. Нүүдэл ба улирал

> **Гол зарчим:** Бууц бүр зөвхөн өөрийн улиралдаа сайн. Нүүдэл мөнгө шаардах ч хоцрох нь үргэлж илүү үнэтэй.

## 1. Нүүдлийн мөчлөг

```
☀️ ЗУСЛАН — голын эрэг
   │ Намар болоход хоцорвол: өвс шарлаж, мал турж эхэлнэ
   ▼
🍂 НАМАРЖАА — уулын энгэр
   │ Өвөл болоход хоцорвол: цас орж, мал үхэж эхэлнэ
   ▼
❄️ ӨВӨЛЖӨӨ — уулын өвөр
   │ Хавар болоход хоцорвол: өвөлжөөнд мал халууцаж, өвчилж эхэлнэ
   ▼
🌱 ХАВАРЖАА — уулын энгэр
   │ Зун болоход хоцорвол: мал хужирсаж, ус руу тэмүүлэн алга болж эхэлнэ
   ▼
☀️ ЗУСЛАН ...
```

> Дээрх байршил нь Хангайн бүсийн жишээ. Хээр, говийн бүсийн бууцны газрын хэлбэрийг [11_world_weather.md](11_world_weather.md) §2.4-өөс үзнэ үү. Тоглогчийн баг бүр **улирал тус бүрт нэг, нийт 4 бууцтай**.

## 2. Бууцны онцлог

| Бууц | Байршил (Хангай) | Давуу тал (цагтаа нүүсэн бол) | Тухайн улирлын гол ажил |
|---|---|---|---|
| ☀️ Зуслан | Голын эрэг | Сүү +50%, ус ойр (ус зөөх хүч 5), айраг исгэх боломжтой | Сааль, айраг, ноос хяргах, Наадам |
| 🍂 Намаржаа | Уулын энгэр | Тарга авах ×2 | Таргалуулах, мал зарах, идэш гаргах, өвс бэлтгэх, хээлтүүлэг |
| ❄️ Өвөлжөө | Уулын өвөр | Салхинаас хамгаалалт, байнгын хашаа саравч, зудын хохирол −30% | Тэжээх, хамгаалах, Цагаан сарын бэлтгэл |
| 🌱 Хаваржаа | Уулын энгэр | Төл амьд гарах 95% | Төллөлт, төл бойжуулах, ингэ хөөслөх |

## 3. Нүүдлийн цонх

Улирал бүр 20 өдөртэй.

```
Улирлын өдөр: 1 ........ 16 | 17  18  19  20 | Дараагийн: 1  2 | 3 ...
                ЭРТ         |   ✅ ЦОНХ      |   ✅ ЦОНХ      | ⚠️ ХОЦРОЛТ
```

| Хугацаа | Үр дагавар |
|---|---|
| ⚡ **Эрт** (1–16 дахь өдөр) | Шинэ бууцны бэлчээр 60% л бэлэн. Хуучин бууцны бонусаа дутуу ашиглана |
| ✅ **Цагтаа** (17–20 + дараагийн 1–2 дахь өдөр) | Шинэ бууцны бүтэн бонус |
| ⚠️ **Хоцрох** (дараагийн улирлын 3 дахь өдрөөс) | Торгууль өдөр ирэх тусам нэмэгдэнэ |

Цонх нээгдэхэд HUD-д мэдэгдэл гарч, өвөө эсвэл хөрш сануулна.

## 4. Хоцорсны торгууль

Хоцорсон хоногийг дараагийн улирлын 3 дахь өдрөөс тоолно.

### ☀️ Зусланд хоцрох (намар болсон)
| Хоног | Үр дагавар |
|---|---|
| 1–5 | Өвс шарлана. Сүү −30%, тарга −1/өдөр |
| 6–15 | Тарга −2/өдөр, зарах үнэ огцом унана |
| 16+ | Тарга −3/өдөр. Тарга 10-аас доош малын үхэх магадлал өдөрт 2% |

### 🍂 Намаржаанд хоцрох (өвөл болсон)
| Хоног | Үр дагавар |
|---|---|
| 1–5 | Анхны цас бэлчээрийг дарна. Бэлчээрийн гарц −50%, тарга −2/өдөр |
| 6–15 | Мал өлсөнө. Хашаагүй мал даарч, эрүүл мэнд −5/өдөр |
| 16+ | Өдөрт 3% мал үхнэ (зудын нөөц тэжээлээр хагасална) |

### ❄️ Өвөлжөөнд хоцрох (хавар болсон)
| Хоног | Үр дагавар |
|---|---|
| 1–5 | Хашаанд мал халууцна. Хөлдсөн бууц гэсч, эрүүл мэнд −2/өдөр |
| 6–15 | Өвчин тархах магадлал өдөрт 5%, сүү −30% |
| 16+ | Төл өвчилж, өдөрт 4% үхнэ |

### 🌱 Хаваржаанд хоцрох (зун болсон)
| Хоног | Үр дагавар |
|---|---|
| 1–5 | Мал хужирсаж тайван бус болно. Мал хариулах хүч ×1.5 |
| 6–15 | Өдөрт 2% магадлалтай мал сүргээс салж ус руу зугтана (олж ирэх «хайлт» даалгавар) |
| 16+ | Өдөрт 5%. Удаан хоцорвол алга болсон мал олдох магадлал буурна |

### Бүсийн нэмэлт нөлөө
| Бүс | Нэмэлт |
|---|---|
| 🌲 Хангай | Намаржаанд хоцорвол цас 2 дахин хурдан зузаарна |
| 🌾 Хээр | Үндсэн утга |
| 🏜️ Говь | Зусланд хоцорвол булаг ширгэж, ус зөөх хүч ×2; өвөлжөөнд хоцрох торгууль бага (хүйтэн хуурай) |

### 4.1. Харагдах сэрэмжлүүлэг
Тоглогч цэс харалгүйгээр байгалийн шинжээр ойлгох ёстой:

| Бууц | Сэрэмжлүүлгийн шинж |
|---|---|
| Зуслан | Өвс ногооноос шар руу шилжинэ, мал туранхай загвартай болно, навч унана |
| Намаржаа | Тэнгэр бүрхэж, анхны цасны ширхэг унана, мал бөөгнөрнө |
| Өвөлжөө | Цас хайлж шалбааг үүснэ, хашаанаас уур савсана, ялаа шумуул гарна |
| Хаваржаа | Мал тал руу, голын зүг ширтэж орилно; хужир долоосон мал харагдана |

## 5. Нүүдлийн зардал

### 5.1. Ачааны нэгж (АН)

| Зүйл | АН |
|---|---|
| Майхан | 1 |
| 4 ханатай гэр + тавилга | 4 + 1 |
| 6 ханатай гэр + тавилга | 7 + 2 |
| 8 ханатай гэр + тавилга | 10 + 3 |
| Жижиг хэрэгсэл (тогоо, шанага, сав) | 0.25 тус бүр |
| Том хэрэгсэл (шахуурга, ширмэн тогоо, хөхүүр, тавиур) | 0.5 тус бүр |
| Цахилгаан хэрэгсэл (ялгагч, хөргөгч, нарны хавтан) | 1 тус бүр |
| Савлагааны машин | 2 |
| Эвхэгддэг хашаа | 2 |
| Хүнс, бүтээгдэхүүн | 100 кг = 1 |
| Өвс | 10 боодол = 1 |

### 5.2. Тээврийн багтаамж

| Тээвэр | Багтаамж (АН) | Түрээс (нэг нүүдэлд) | Өөрийнх бол |
|---|---|---|---|
| Морь (хөтөлгөөр) | 1 | — | Үнэгүй |
| Тэмээ | 3 | 25,000 / тэмээ | Үнэгүй |
| Үхэр тэрэг | 4 | 40,000 | Үнэгүй |
| Морин тэрэг | 4 | 40,000 | Үнэгүй |
| Мотоцикл | 0.5 | — | Шатахуун 10,000 / өдөр |
| Жижиг ачааны машин | 10 | 120,000 (жолоочтой) | Шатахуун 30,000 / өдөр |
| Ачааны том машин | 25 | 300,000 (жолоочтой) | Шатахуун 70,000 / өдөр |

Багтаамж хүрэхгүй бол **хоёр удаа зөөнө**: замын хоног ×2, туслах, хүнсний зардал нэмэгдэнэ.

### 5.3. Нүүдлийн зардлын бүрэлдэхүүн

| Зардал | Хэмжээ |
|---|---|
| Тээвэр | Дээрх хүснэгтээр |
| Туслах хүн | 40,000 / хүн / өдөр (гэр буулгах, барих, мал туух) |
| Замын хүнс | 8,000 / хүн / өдөр |
| Бууц засвар | Зуслан 0–20,000; намаржаа 20,000–50,000; хаваржаа 30,000–80,000; өвөлжөө 100,000–300,000 (өөрийн байнгын хашаатай бол 30,000) |
| Бэлчээрийн эрх | Өөрийн багийн бууц үнэгүй; отрын бэлчээр 100,000–300,000 ([11](11_world_weather.md) §5.1) |

### 5.4. Замын хоног
Нүүдэл **их газрын зураг** дээр явагдана ([11_world_weather.md](11_world_weather.md) §6). Сүрэг явганаар явна, машин зөвхөн ачааг зөөнө.
- Багийн бууц хооронд: 0.5–1 өдөр (газрын хэлбэр, бууцны зайнаас хамаарна).
- Отор, нутаг сэлгэх үед: 2–6 өдөр.
- Мал замд ядарч, хоног тутам тарга −3.

### 5.5. Жишээ тооцоо

| Тохиолдол | Ачаа | Тээвэр | Нийт зардал (≈) | Улирлын орлоготой харьцуулахад |
|---|---|---|---|---|
| Эхлэл: майхан → намаржаа (1 өдөр) | 1.5 АН | Морь + 1 тэмээ түрээс | 25,000 + хүнс 8,000 + засвар 30,000 = **63,000** | ≈ 9% |
| Дунд үе: 6 ханатай гэр → өвөлжөө (1 өдөр), эхнэртэй | ≈ 15 АН | Жижиг машин + 2 өөрийн тэмээ | Шатахуун 30,000 + туслах 80,000 + хүнс 24,000 + засвар 200,000 = **334,000** | ≈ 10% |

> Хангайн бүсэд тэмээ байхгүй тул ачааг тэрэг, машинаар зөөнө ([11_world_weather.md](11_world_weather.md) §4).

## 6. Зардал бууруулах арга

| Арга | Нөлөө |
|---|---|
| Өөрийн тэмээ, тэрэг, машин | Түрээсийн зардал арилна |
| Эхнэр, хүүхэд | Туслах хөлслөх шаардлага багасна |
| **Хот айл болох** | Хүндлэл 50+ хөрштэй хамт нүүвэл тээвэр, туслах зардал хуваагдана (−40%) |
| Өөрийн өвөлжөө эзэмших (3,000,000₮) | Өвөлжөөний засвар 30,000₮ болж буурна, хашаа саравч хадгалагдана |
| Эвхэгддэг хашаа | Зуслан, намаржаанд хашаа барих хүч −50% |
| Гэрийн хэмжээ | Том гэр нь хүндлэл, тав тух өгнө, гэхдээ ачаа их болно: **сонголтын цэг** |

## 7. Мөнгө хүрэхгүй бол

Тоглогч бүрэн гацахгүй. Гарц бүр өөрийн үнэтэй:

| Гарц | Үнэ |
|---|---|
| Мал зарах | Хоцорсон үед тарга бага, үнэ уналттай |
| Ачаагаа хөнгөлөх | Зарим хэрэгсэл хуучин бууцанд үлдэнэ (дараа нь буцаж авч болно, эрсдэлтэй) |
| Хөршөөс зээлэх | Хүндлэл 40+ шаардлагатай, буцааж өгөхгүй бол хүндлэл −15 |
| **Мал тавих** | Малаа айлд маллуулна. Тэр айл сүү, ноосыг нь авч, төлийг хуваана |
| Банкны зээл | 3 дахь шатнаас нээгдэнэ, улирлын хүү 5% |

## 8. Нүүдлийн өдрийн тоглолт

### 8.1. Бэлтгэл
1. **Нүүх өдрөө сонгох:** Өвөө эсвэл зурхайн хуанли «сайн өдөр»-ийг зөвлөнө. Сайн өдөр нүүвэл замын эрсдэл −20%, хүндлэл +2.
2. **Гэр буулгах:** Туурга → бүслүүр → унь → тооно → хана гэсэн дарааллаар.
3. **Ачаа ачих оньсого:** Тэмээ, тэрэгний хоёр талын жинг тэнцүүлнэ. Тэнцвэргүй бол замд ачаа унах эрсдэлтэй.
4. **Бууцаа цэвэрлэх:** Хог хаягдлыг цэвэрлэж, галаа зөв унтраана → хүндлэл +3.
5. **Ерөөл:** Явахдаа сүү цацаж ерөөнө.

### 8.2. Замд
Гэрээ ачсаны дараа тоглоом **их газрын зураг** руу шилжинэ. Цуваа (тоглогч + сүрэг + ачаа) дараагийн бууц руу явна.
- Сүргээ тууж, хоцорсон малаа цуглуулна.
- Санамсаргүй үйл явдал (нэг аялалд 1–2):

| Үйл явдал | Сорилт |
|---|---|
| Гол гатлах | Гүехэн гарам олох, мал урсах эрсдэл |
| Шуурга | Сүргээ бөөгнөрүүлж хамгаалах |
| Мал төөрөх | Хайж олох |
| Чоно | Хамгаалах, нохой, морь тусална |
| Аян замын айл | Цай уух, мэдээ сонсох, хүндлэл + |
| Ачаа унах | Ачаагаа дахин тэнцвэржүүлэх |

### 8.3. Буух
Бууцандаа ирэхэд тоглоом **3D горим** руу шилжинэ.
1. Гэрийн байршлаа сонгох (салхины зүг, усны зай, бэлчээр).
2. Гэр барих: хана → тооно, унь → туурга → бүслүүр.
3. Хашаа барих эсвэл засах.
4. Голомтоо асааж, анхны цайгаа чанана.

## 9. Баг, бууц ба сонголт

Тоглогчийн баг бүр **улирал тус бүрт нэг бууцтай** ([11_world_weather.md](11_world_weather.md) §2.4). Тиймээс стратегийн гол сонголтууд:

| Сонголт | Хэзээ | Дэлгэрэнгүй |
|---|---|---|
| **Баг сонгох** | Тоглоом эхлэхэд | [11](11_world_weather.md) §3.1: бүс, бэлчээр, ус, зай, эрсдэл |
| **Бууц доторх байршил** | Буух бүрт | Гэр, хашааны байрлал: салхи, ус, бэлчээрийн хэсэг |
| **Бэлчээрийн хэсгийг ээлжлэх** | Өдөр бүр | Бууц бүр 3–5 бэлчээрийн хэсэгтэй. Нэг хэсгийг хэт ашиглавал доройтоно |
| **Отор** | Зуд, гангийн үед | [11](11_world_weather.md) §5.1 |
| **Нутаг сэлгэх** | Нүүдлийн цонхонд | [11](11_world_weather.md) §5.2 |

### 9.1. Бууцны үзүүлэлт

| Үзүүлэлт | Тайлбар |
|---|---|
| Бэлчээрийн чанар | 0–100, өмнөх ашиглалтаас хамаарна (бэлчээрийн хэсэг бүрээр) |
| Даац | Хэдэн ХТ мал багтах |
| Ус | Гол, булаг, нуур, худаг |
| Хамгаалалт | Салхи, цаснаас |
| Чонын эрсдэл | Бага / дунд / өндөр |
| Хөршүүд | Ижил багийн NPC айлууд, хот айл болох боломж |

### 9.2. Бэлчээрийн хамгаалалт
Тоглогч жил бүр ижил 4 бууцандаа буудаг тул бэлчээрийн доройтол **урт хугацаанд хуримтлагдана** ([04_livestock.md](04_livestock.md) §7). Даацаасаа хэтэрсэн сүрэгтэй тоглогч дараах аргаар зохицуулна:
- Малаа сонгон зарах
- Сүргээ хувааж, нэг хэсгийг туслах малчинтай өөр багт отор хэлбэрээр байлгах
- Илүү том даацтай баг руу нутаг сэлгэх
