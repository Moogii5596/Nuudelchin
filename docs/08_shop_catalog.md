# 08. Дэлгүүрийн каталог

Худалдаж авч болох бүх зүйлийн нэгдсэн жагсаалт. Үнэ нь сумын төвийн суурь үнэ. **Шат** нь нээгдэх ахиц дэвшлийн шат юм ([10_progression.md](10_progression.md)).

## 0. Хаана юу зарагдах вэ

Зах бүр өөр барааны сонголттой. Ахисан шатны зүйлсийг авахын тулд их газрын зураг дээр аймгийн төв, нийслэл рүү аялна.

| Ангилал | Сумын төв | Аймгийн төв | Нийслэл |
|---|---|---|---|
| Хүнс, тэжээл, вакцин | ✅ | ✅ | ✅ |
| Нутгийн мал | ✅ (бүсийн дүрмээр) | ✅ | ❌ |
| Үүлдрийн мал | ❌ | ✅ (бүсийн) | ✅ (Голштейн, Галшар, Сэлэнгэ) |
| Сүүний 0–3 шатны хэрэгсэл | ✅ | ✅ | ✅ |
| Сүүний 4–5 шат, цахилгаан | ❌ | ✅ | ✅ |
| Савлагааны машин | ❌ | ❌ | ✅ |
| Гэр, хашаа | Хуучин гэр, хашаа | ✅ | ✅ |
| Тэрэг, мотоцикл | ✅ | ✅ | ✅ |
| Машин | ❌ | Хуучин | Шинэ, хуучин |
| Нохой, муур | ✅ | ✅ | ✅ |

Бүсийн малын дүрэм: Хангайн захад тэмээ, Говийн захад адуу зарагдахгүй ([11_world_weather.md](11_world_weather.md) §4).
