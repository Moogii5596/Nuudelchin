# Тэнцвэрийн симулятор

`game/src/sim/`-ийг 3D-гүйгээр шууд ашиглаж, олон seed × тоглогчийн стратегиар тоглуулна (architecture.md §8).

- **M1-д бичигдэнэ:** стратегиуд (идэвхтэй, залхуу, туслахтай), олон seed, тайлан (зорилгод хүрэх хугацаа, мөнгөний урсгал).
- Ажиллуулах (M1-ийн дараа): `cd game && npx tsx ../tools/balance_sim/run.ts --seeds 200 --days 120`
- Хуучин Python загвар (4 улирлын дүрэм): `legacy_sim.py` — зөвхөн лавлагаа.
